# 章节子任务书

父任务在大纲和 `CHAPTERS` 已写入后，每章发一个子任务。把下面整段交给子任务，替换花括号。不要让子任务自行决定章号、文件名、运行时名或基准算例。

```text
你负责一门离线交互式自学教程中的单独一章。只写这一个文件：
{课程目录}/{file}

先读这些文件再动笔，写的时候对标它们，不要发明第二套页面：
- {课程目录}/{样章文件}（若本章就是样章，则对标用户指定的样式样章）
- {课程目录}/assets/css/course.css
- {课程目录}/assets/js/course.js（只用已有运行时 API）
- {课程目录}/assets/js/{计算文件}
- 课程合同：{技能目录}/course-contract.md
- 领域包（没有则删掉这一行）：{技能目录}/domains/{领域文件}

本章身份（不得改）：
- id：{id}
- 章号：{no}
- 篇：{stageName}
- 标题：{title}
- 运行时全局名：{runtime}（全文只用这一个；initChapter、ui、errors 都挂在它上面）
- 作者：{author}（若为「不署名」：不要写 meta author，不要放作者 chip；否则可见 chip 只放一枚，meta author 只写一条）
- 前置：{prereq}
- 学习目标：{objectives}
- 小节大纲：{sections}
- 基准算例（只许引用，不许改数）：{baseline}
- 必须写进正文的易错点：{mistakes}
- 必须写进正文的避坑点：{pitfalls}
- 演示清单：{demos}（空间关系用 3D，曲线用 Plot 或 canvas2d，步骤用分步控件）

写作要求：
- 每节从问题、符号与单位、基准算例、易错、避坑、可操作对象，由浅入深写完。
- 有公式时只用 \( \) 与 \[ \]。没有公式就不要编。
- 章末包含：本章避坑清单、自测题（不少于 8 题，含多选，用 ui.quiz）、术语表、本章小结与延伸阅读。
- 本章专用 CSS 类名以 c{no}- 为前缀，写在本文件 style 里。
- 每个演示独立 IIFE + try/catch，错误推入 {runtime}.errors。
- 文末调用 {runtime}.initChapter('{id}')。
- 资源只用相对路径，禁止 CDN、禁止 type="module"。
- 软件菜单与标准限值不作定论，写明以文档或标准原文为准。
- 示例参数是教学用，不写成未标明的真实产品或个人数据。

禁止：
- 不要修改 course.js、course.css、计算文件、index.html 和其他章节。
- 不要重复插入作者标签，不要编造作者。
- 不要新增未在基准算例中的同名参数。
```

父任务收回各章后只做这些事：核对注册表、首页作者是否符合约定、跨章链接、共用计算是否仍被旧章调用，然后运行 `scripts/validate_course.py`。
