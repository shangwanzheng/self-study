# 领域包：车辆多体动力学

主题涉及车辆多体动力学、车辆动力学、悬架、五连杆、K&C、操稳、平顺性、轮胎力、转向、静载荷、弹性元件、整车仿真，或用户要求与「车辆多体动力学仿真交互式教程」保持一致时，先读本文件，再写大纲。

不要用于失败用例分析、自动化跑测、冒烟/L0、PPP 用例、`.script`、Jira 或 PTS 缺陷。

## 运行时与模板

续写标杆课，或新开一门车辆课时：

- 运行时全局名保持 `VMD`，不要改成 `Course`。
- 计算文件保持 `assets/js/vmd-models.js`。
- 标杆目录：本技能内的 `template/`。整门课都在这里，不要再去别的盘找。
- 续写标杆课：直接改 `template/` 里的章节，不复制第二套 `assets/`。用户未另指定作者时，作者是「陶星宇」。
- 另开一门车辆课：从 `template/assets/` 复制运行时。用户未指定输出目录时，放到当前工作区下的 `<课程名>/`，不要写进 `template/`。
- 坐标默认 ISO 8855（X 前、Y 左、Z 上）。3D 场景 Z 轴向上，长度用米；毫米硬点用 `VMD.three.mm`。

轴距、轮距、质量、质心、侧偏刚度、弹簧与侧倾角刚度以 `VMD.data.refCar` 为准。这就是本课基准算例。章节可以引用这些数并写清单位换算，不要改成另一辆车，也不要把教学示例写成某款量产车数据。

非车辆课禁止引用 `refCar` 和 `VMD.susp`、`VMD.tire`、`VMD.veh`。

## 标准覆盖

车辆多体这条线的标准覆盖是：多体基础、坐标系与载荷转移、模板/子系统/装配、悬架定位、五连杆、弹性元件与柔性体、轮胎力、转向、K&C、静载荷、操稳理论、操稳工况、平顺性、整车流程、综合避坑。已有 15 章时不要重复生成。

五篇在这门课上的篇名：共同语言、部件与子系统、分析方法、性能、实战。

## 正文必须落到仿真里怎么错

用户给出关键词时，按下表补全，而不是只写教科书定义。

| 主题 | 正文必须落到 |
| --- | --- |
| 多体基础 | 约束与力元的差别、自由度与冗余、DAE、积分器步长不等于输出步长 |
| 坐标系 / 载荷转移 | ISO、SAE、Adams 三套方向；同一侧向加速度在三套坐标里的符号 |
| 子系统 | 模板、子系统、装配、硬点、对称、通讯器；改质量后是否写回子系统 |
| 悬架 / 五连杆 | 定位参数定义方向、主销、侧倾中心适用条件、装配分支、硬点灵敏度 |
| 弹性元件 | 衬套六向刚度与频变、用超高刚度冒充运动副、稳定杆与侧倾刚度 |
| 轮胎力 | 侧偏角定义、刷子模型与魔术公式、联合滑移、松弛长度、坐标系 |
| 转向 | 阿克曼、转向比、万向节不等速、转向柔度进操稳的路径 |
| K&C | 同向/反向轮跳、侧向力与回正力矩柔度、从曲线取轮跳转向和侧倾中心 |
| 静载荷 | 静平衡失败的零刚度自由度、设计载荷与整备姿态、硬点力提取 |
| 操稳 | 不足转向度、K 与 C 的贡献、特征车速、工况输入怎么加到模型上 |
| 平顺 | 偏频、阻尼比、路面谱、加权加速度；悬架参数改变哪一段频率 |
| 整车 | 质量校核、轮胎接地、驾驶员模型、事件、求解设置、仿真与试验对标 |

易错要具体，例如「3-1-3 的第二个角不是俯仰角」「运动学正确不代表约束反力可信」。模型对象写到部件、约束、力元、工况、输出。
