导论与基础：先把“车”和“多体”看明白

0.2 多体系统的基本要素与自由度 入门

多体系统（Multibody System, MBS）是由多个物体通过约束和力元连接而成的机械系统。车辆就是一个典型的多体系统：车身、副车架、摆臂、转向节、转向拉杆、稳定杆、车轮……它们之间用球铰、转动副、衬套连接，再加上弹簧、减振器和轮胎力。

部件 Part

刚体（6 个自由度：3 平动 + 3 转动），需要质量、质心、惯量张量；需要考虑变形时用柔性体。

约束 Joint

运动副，限制相对运动：转动副、球铰、移动副、圆柱副、万向节、固定副等。

力元 Force

不限制运动、只产生力：弹簧、减振器、衬套、限位块、稳定杆、轮胎力、气动力。

驱动 Motion

强制规定位移或转角：K&C 台架的轮跳位移、转向盘转角输入。

自由度怎么数（Grübler–Kutzbach 公式）

DOF = 6 · n − Σ cj（空间机构，n 为运动部件数，不含大地）
运动副约束数 c保留的相对运动车辆中的典型位置
固定副 Fixed6无焊接件、简化的刚性连接
转动副 Revolute51 转动摆臂与副车架（刚性简化时）
移动副 Translational51 平动齿条与转向器壳体
圆柱副 Cylindrical41 平动 + 1 转动麦弗逊减振器活塞杆与缸筒
万向节 Universal/Hooke42 转动转向拉杆内点、传动轴
球铰 Spherical33 转动下摆臂球头、拉杆外球头
自由度计算器：数一数悬架有几个自由度
部件与运动副数量
提示：多体软件（如 Adams）在模型检查时会报告自由度和“冗余约束”。冗余约束不一定导致报错，但会让约束反力无法唯一确定，K&C 和载荷分解时必须消除。
把平面机构直接用 3D 转动副搭建，自由度公式会算出负数（过约束）。这不是模型“动不了”，而是有些约束重复限制了同一个方向。工程上常把其中一个转动副换成球铰或万向节，或者改用衬套连接。

0.4 车辆仿真体系全景 入门

同一个整车多体模型，换不同的路面、驾驶员和输出，就能服务于不同性能领域。下表是底盘开发中最常见的仿真类别：

操纵稳定性 Handling

稳态回转、阶跃、频响、双移线、蛇行、中心区。关注不足转向、响应速度、侧倾、稳定裕度。

K&C 特性

悬架在轮跳、侧倾、侧向/纵向力、回正力矩下的定位参数变化，是操稳和平顺性的“底层基因”。

平顺性 Ride

随机路面与冲击路面下的车身加速度、座椅振动、悬架动行程、轮胎动载荷。

耐久与载荷分解

在虚拟试验场路面上提取摆臂、副车架、车身接附点载荷，为疲劳分析提供输入。

NVH 低频

动力总成悬置解耦、怠速抖动、路噪传递路径（中低频）、转向盘抖动（摆振）。

制动与驱动

制动力分配、制动跑偏、制动点头、起步后坐、扭矩转向、ABS/ESC 联合仿真。

转向系统

转向力感、EPS 助力曲线、中心区刚度、回正性能、转向系统摩擦与刚度。

智能驾驶与控制

实时车辆模型 + 控制器的 MIL/SIL/HIL，驾驶模拟器（DIL），ADAS 场景测试。

0.8 轮胎力学基础 入门 进阶

汽车几乎所有的操控力都来自四块巴掌大的接地印迹。理解轮胎有三个关键概念：

  • 侧偏角 α：车轮平面方向与轮心速度方向的夹角。轮胎只有在“斜着滚”时才会产生侧向力，就像人走路要斜着用力才能转弯。
  • 侧偏刚度 Cα：小侧偏角时侧向力与侧偏角之比 Fy ≈ Cα·α，乘用车单胎约 50–100 kN/rad（约 900–1700 N/°）。它是二自由度模型里最关键的参数。
  • 滑移率 κ：驱动/制动时轮胎周向速度与车速之差的比例，κ = (ωRe − u)/u，决定纵向力。

轮胎力随侧偏角先线性增长、再饱和、甚至下降。工程中最常用的描述是 Pacejka 的魔术公式（Magic Formula, MF）：

y(x) = D · sin{ C · arctan[ B·x − E·(B·x − arctan(B·x)) ] }（x 为 α 或 κ，y 为 Fy 或 Fx）
系数名称物理意义
D峰值因子曲线峰值 = μ·Fz
C形状因子决定曲线形状，侧向力约 1.3，纵向力约 1.65
B刚度因子B·C·D = 原点斜率（侧偏刚度或纵滑刚度）
E曲率因子控制峰值附近的弯曲程度和峰值位置
魔术公式交互：调整 B、C、D、E 和垂向载荷
图中同时画出 0.5Fz、Fz、1.5Fz 三条曲线：载荷翻倍，侧向力却不到两倍，这就是轮胎载荷敏感性。它是“侧倾刚度分配能改变不足转向”的根本原因（见 1.5 节）。
线性区（侧偏角约 2–3° 以内）对应日常驾驶，二自由度模型就够用；峰值附近对应极限操控和 ESC 介入；超过峰值后侧向力下降，前轴先饱和会“推头”，后轴先饱和会“甩尾”。

操纵稳定性（Handling）：车怎么听话、稳不稳

1.1 基本概念与评价体系 入门

操纵稳定性包含两层意思：操纵性——汽车能否按驾驶员通过转向盘给定的方向行驶；稳定性——遇到外界干扰（侧风、路面不平、突然松油门）时，汽车能否抵抗干扰并保持稳定行驶。两者相互关联，统称操稳（GB/T 12549 中有完整的术语定义）。

人—车—路闭环系统

驾驶员感知路径与车辆状态
转向系统转向盘 → 齿条 → 前轮转角
轮胎侧偏角 → 侧向力
车身运动横摆、侧向、侧倾
反馈路感、侧向加速度、视觉

真实驾驶是闭环的：驾驶员不断修正转向。但驾驶员的个体差异很大，所以工程上更常用开环试验（给定转向输入，测车辆响应）来客观评价车辆本身的特性，再配合闭环试验（双移线、蛇行）和主观评价。

稳态响应

给定转向角并保持，车辆达到稳定圆周行驶时的特性：转多大的弯、需要多大转角、车身侧倾多少。核心指标是不足转向度。

瞬态响应

转向输入变化过程中车辆的响应：反应快不快、有没有超调、振荡衰减多快。核心指标是反应时间、超调量、固有频率与阻尼比。

1.2 线性二自由度模型（自行车模型） 进阶

二自由度模型是操稳理论的基石。虽然简单，但它能解释不足转向、特征车速、瞬态响应等核心现象，也是控制器设计和多体模型合理性检查的“标尺”。

模型假设

  • 车速 u 恒定，只考虑侧向运动（v 或 β）和横摆运动（r）两个自由度；
  • 忽略悬架、侧倾和载荷转移，左右车轮合并为前后各一个“等效车轮”；
  • 轮胎工作在线性区：Fy = Cα·α（Cα 取整轴侧偏刚度，为正值）；
  • 忽略转向系统，直接以前轮转角 δ 为输入；小角度近似。

运动学：侧偏角从哪来

车辆以速度 u 前进、以 r 横摆时，前后轴处的速度方向不同。设质心到前轴距离为 a，到后轴距离为 b，轴距 L = a + b：

αf = δ − ( β + a·r / u )　　　αr = − ( β − b·r / u )（α 取使侧向力为正的方向）

动力学方程

m·u·( β̇ + r ) = Cf·αf + Cr·αr　　　（侧向力平衡）
Iz·ṙ = a·Cf·αf − b·Cr·αr　　　　（横摆力矩平衡）

整理成状态方程（状态 x = [β, r]T，输入 δ）：

β̇ = −(Cf+Cr)/(m u)·β + [ (b Cr − a Cf)/(m u²) − 1 ]·r + Cf/(m u)·δ
ṙ = (b Cr − a Cf)/Iz·β − (a² Cf + b² Cr)/(Iz u)·r + a Cf/Iz·δ
可以把车想象成一根被前后两个“侧向弹簧”（轮胎侧偏刚度）支撑的杆。前轮一打方向，前弹簧先产生力，车头开始转；车头转动又让后轮产生侧偏角，后弹簧出力“稳住”车尾。前后力的力矩平衡决定了车最终转多快。
不同教材的符号约定不同：余志生《汽车理论》把侧偏刚度取负值，稳定性因数写作 K = m/L²·(a/k2 − b/k1)；本文取正值，写作 K = m/L²·(b/Cf − a/Cr)，两者完全等价。对照公式时先统一符号。

1.3 稳态转向特性 进阶

令 β̇ = ṙ = 0，可得稳态横摆角速度增益：

r / δ = ( u / L ) / ( 1 + K·u² )　　　K = ( m / L² )·( b / Cf − a / Cr )（K：稳定性因数，s²/m²）

K > 0 不足转向

车速越高需要的转角越大，转弯半径随车速增大。存在特征车速 uch = 1/√K，此时增益最大，为中性车的一半。

K = 0 中性转向

增益 u/L 随车速线性增大，转弯半径始终等于阿克曼半径 L/δ。实际车辆难以在全工况保持。

K < 0 过多转向

增益随车速急剧增大，在临界车速 ucr = 1/√(−K) 处趋于无穷，车辆失稳。乘用车设计必须避免。

工程常用的等价指标

不足转向度：Kus = Wf/Cf − Wr/Cr = K·L·g　（rad/g，常换算为 °/g）
前轮转角：δ = L/R + Kus·ay/g　　　前后轴侧偏角差：αf − αr = K·L·ay
转弯半径比：R/R0 = 1 + K·u²　　　静态储备系数：S.M. = Cr/(Cf+Cr) − a/L

其中 Wf, Wr 为前后轴荷（N）。不足转向度的物理意义非常直观：每增加 1 g 侧向加速度，需要额外多打多少前轮转角。乘用车前轮处一般在 2–5 °/g 量级，乘以转向比（约 14–18）就是转向盘上的角度梯度。

为什么乘用车都设计成适度不足转向？过多转向存在临界车速，高速下微小扰动就会被放大；中性转向在载荷、胎压、路面变化时很容易变成过多转向；适度不足转向既有稳定裕度，又不至于反应迟钝。特征车速一般设计在 65–100 km/h 左右，高速稳定性要求高的车型取更低的特征车速（更多不足转向）。

1.4 瞬态响应与频率特性 进阶 高级

二自由度模型是一个二阶系统。其特征方程和横摆角速度传递函数为：

s² + 2ζω0·s + ω0² = 0
ω0² = CfCrL²/(m Iz u²)·(1 + K u²)　　　2ζω0 = (Cf+Cr)/(m u) + (a²Cf + b²Cr)/(Iz u)
r(s)/δ(s) = Gr·(1 + τ s) / (1 + 2ζ s/ω0 + s²/ω0²)　　Gr = (u/L)/(1+Ku²)，　τ = m·a·u/(L·Cr)
  • 固有频率 ω0 随车速升高而降低：车越快，横摆响应越“慢”；不足转向（K>0）能提高高速时的 ω0。
  • 阻尼比 ζ 随车速升高而降低：高速时更容易出现横摆超调和振荡。
  • 分子零点 τ 让横摆响应在初期“提前”，前轴侧偏刚度越大、后轴越硬，响应越敏捷。
  • 横摆惯量 Iz 常用动力学指数 k²/(ab) 表示（Iz = m k²），乘用车约 0.8–1.1；越小响应越快。

试验中常发现：横摆角速度响应很快，但侧向加速度明显滞后——这是因为侧向加速度需要先建立后轴侧偏角。主观上“车头指向快但车身跟不上”就是这种相位差过大。增大后轴侧偏刚度（更宽或更硬的后胎、后悬侧向刚度和侧向力 toe-in）能有效减小它。

1.5 非线性与极限工况：载荷转移与操稳图 高级

线性模型只在小侧向加速度（约 0.3–0.4 g 以内）成立。侧向加速度增大后，三个非线性因素开始主导：轮胎饱和、左右载荷转移和轮胎载荷敏感性。它们叠加起来，决定车辆在极限时是“推头”还是“甩尾”。

左右载荷转移

转弯时离心力作用在质心上，内侧车轮卸载、外侧车轮加载。每个轴承担的载荷转移量由侧倾刚度分配和侧倾中心高度决定：

ΔFzf = (m·ay/tf)·[ Kφf/(Kφf+Kφr)·h′ + (b/L)·hrf ]
ΔFzr = (m·ay/tr)·[ Kφr/(Kφf+Kφr)·h′ + (a/L)·hrr ]
侧倾梯度：φ/ay = m·h′ / (Kφf + Kφr − m·g·h′)（h′：质心到侧倾轴线的距离）

由于轮胎载荷敏感性，同一根轴上左右载荷差越大，这根轴能提供的总侧向力越小（见 0.8 节魔术公式中 1.5Fz 曲线的峰值不到 Fz 的 1.5 倍）。所以：前轴承担的载荷转移越多 → 前轴等效侧偏刚度越低 → 不足转向越强。这正是调稳定杆能调不足转向的原理。

“加粗后稳定杆让车更灵活”在线性区成立，但它同时让后轴更早饱和；在低附着路面或极限时可能从不足转向突变为过多转向。调校时必须同时看线性区梯度和极限行为，不能只看一个点。

极限稳定性分析方法

  • β–r 相平面：以质心侧偏角和横摆角速度为坐标画轨迹，存在稳定区域边界；ESC 控制常以 β 和 β̇ 的阈值判断失稳。
  • β 方法（Beta Method）/ 横摆力矩图（MMM）：Milliken 提出，在 (β, δ) 网格上计算整车可产生的侧向力和横摆力矩，直观展示极限能力与可控性。
  • 多体非线性仿真：直接在多体软件中用详细悬架、非线性衬套、MF 轮胎跑极限工况，是工程上最可靠的方法。

二自由度模型告诉我们“什么参数重要”，多体模型则要把这些参数从真实结构中算出来。整车操稳模型的可信度取决于下列子系统：

驾驶员模型

  • 开环：直接给定转向盘转角（或力矩）时间历程，适用于阶跃、脉冲、扫频、正弦停滞等标准开环试验。
  • 闭环路径跟随：单点/多点预瞄模型、郭孔辉的最优预瞄曲率模型、MacAdam 模型等。预瞄时间和反应滞后会影响双移线结果，对标时应与试验驾驶员水平相当。
  • 车速控制：PI/PID 控制油门和制动，或直接给定纵向速度约束。

求解设置与数据处理

  • 动力学仿真前先做静平衡，再给初速度；直线段保留 1–2 s 让系统稳定后再施加转向。
  • 积分器：刚性系统常用 BDF 类（如 GSTIFF、WSTIFF）或 HHT；误差容差一般从 1e-3 起试，结果敏感时收紧；输出步长要足够细（如 100–200 Hz）以捕捉瞬态。
  • 后处理：统一坐标系和符号（ISO/SAE）、与试验一致的滤波方式（如低通 2–4 Hz 求稳态指标）、指标拟合区间（例如不足转向度取 0.1–0.4 g 线性段）。
整车模型常见“隐形错误”：① 轮胎文件的名义载荷、胎压与实车不符；② 转向系统没有柔度（齿条刚性固定），回正力矩柔度转向被漏掉；③ 衬套只设了线性刚度，大侧向力下柔度被高估；④ 稳定杆连杆角度不对导致稳定杆刚度在车轮处被错误放大或缩小；⑤ 车身惯量随意估计，阶跃响应永远对不上。

与试验对标的推荐顺序

  1. 质量参数：轴荷、质心高、惯量（称重、倾斜试验、惯量台）；
  2. K&C：前后悬架逐项对标（见第 2 章），这是整车对标的前提；
  3. 轮胎：用轮胎六分力试验数据拟合 MF 参数，确认侧偏刚度与载荷敏感性；
  4. 整车稳态：稳态回转的不足转向度、侧倾梯度；
  5. 整车瞬态：阶跃与频响（此时再细调减振器、衬套阻尼、轮胎松弛长度、转向系统摩擦）。

CHAPTER 2

K&C 分析：悬架如何让车轮“动”和“让”

K（Kinematics，运动学）研究车轮跳动和转向时由连杆几何决定的定位参数变化；C（Compliance，弹性运动学/柔度）研究受力时由衬套和部件弹性变形引起的定位参数变化。两者合起来，就是悬架的“性格档案”。

2.1 K&C 的概念与试验台 入门

K：运动学特性

假设所有连杆和衬套都是刚性的，只由硬点几何决定。典型问题：车轮上跳 50 mm，前束、外倾、轮距各变多少？侧倾中心在哪？

C：弹性运动学特性

考虑衬套、连杆、副车架等的弹性。典型问题：车轮受 1 kN 侧向力，前束改变多少度？制动时车轮后移多少毫米？

K&C 试验台（如 MTS、ABD SPMM 等）把车身夹紧固定，让每个车轮站在可以上下、左右、前后运动并施力的平台上，通过测量轮心位移和车轮姿态得到 K&C 曲线。多体仿真中的 K&C 分析就是把这个台架“虚拟化”：车身固定在大地上，在轮心或接地点施加位移或力。

K&C 试验台动画：不同工况下车轮怎么动

K&C 之所以重要：它是“悬架设计参数”和“整车操稳/平顺性能”之间的桥梁。整车不足转向度中通常有一半以上来自 K&C（侧倾转向、柔度转向、外倾变化），而不是轮胎本身。

2.2 运动学：瞬心、侧倾中心与外倾变化 进阶

在正视图中，独立悬架的转向节相对车身做平面运动。根据三心定理，转向节相对车身的瞬时转动中心（Instant Center, IC）就是上下摆臂延长线的交点（麦弗逊则是下摆臂延长线与过减振器上支点、垂直于减振器轴线的直线的交点）。

  • 侧倾中心（Roll Center, RC）：轮胎接地点与 IC 的连线与车辆中心面的交点。侧向力通过 RC 传给车身而不产生侧倾力矩，RC 越高，“几何载荷转移”越多、侧倾越小，但轮距变化越大（顶起效应 jacking）。
  • 正视摆臂长度（FVSA）：IC 到车轮接地点的距离。外倾增益近似为 1/FVSA（rad/m），FVSA 越短，上跳时负外倾增加越快。
  • 轮距变化：接地点相对车身的横向移动。轮距变化大会产生轮胎侧偏角扰动，影响直线行驶和平顺性。

2.3 转向几何：Bump Steer 与阿克曼 进阶

Bump Steer（跳动转向）

车轮跳动时，转向节上的拉杆外点沿着“转向节运动”画出一条轨迹，而转向拉杆又迫使外点沿着以拉杆内点为圆心的圆弧运动。两条轨迹不重合，差值就会推动转向节绕主销转动，产生前束变化。这就是 Bump Steer，也是侧倾转向的主要来源。

  • 经典设计原则：拉杆延长线应通过 IC，且拉杆内点落在上下摆臂内点连线上，此时 Bump Steer 近似为零（上面演示中的紫色十字）。
  • 工程上常有意保留少量 Bump Steer：前悬上跳 toe-out（外侧车轮在侧倾中向弯外转）可增加不足转向；后悬上跳 toe-in 有同样效果。
  • 拉杆内点高度误差几毫米就会明显改变 Bump Steer，因此它是 K&C 优化中最敏感的硬点之一（见 2.9 节灵敏度分析）。

阿克曼转向几何

低速转弯时，为了让四个车轮都绕同一个中心纯滚动，内轮转角应大于外轮转角，满足 cot δo − cot δi = t/L。实际车辆常用阿克曼百分比描述接近程度：100% 为理想阿克曼，0% 为平行转向，负值为反阿克曼。

阿克曼几何：内外轮转角与转向中心
虚线为各车轮的垂线：理想阿克曼时三条线交于后轴延长线上同一点。阿克曼不足时外轮垂线交点偏离，低速转弯会出现轮胎拖滑与磨损；高速大侧向加速度时，由于外轮载荷大、需要更大侧偏角，赛车常采用较低甚至反阿克曼。

2.4 纵向几何：抗点头与抗抬头 进阶

制动时，惯性力使载荷从后轴转移到前轴，车头下沉（点头），车尾抬起。如果悬架在侧视图中的瞬心（SVIC）布置合适，一部分制动力可以通过连杆直接“托住”车身，减少弹簧压缩——这就是抗点头（Anti-dive）和抗抬头（Anti-lift）。驱动时对应的是抗下蹲（Anti-squat）。

2.5 弹性运动学：衬套与弹性中心 进阶 高级

悬架连杆与车身之间大多不是刚性铰接，而是橡胶衬套。衬套在六个方向都有刚度（径向、轴向、扭转、偏转），通常是非线性且有迟滞的。它们的作用是隔振降噪，但也带来“受力就变形”的副作用——车轮在侧向力、纵向力下会产生额外的前束和外倾变化。

径向刚度

决定连杆方向的柔度，常见数千至数万 N/mm，可通过开孔、内外管设计实现两个径向方向刚度不同。

轴向/扭转刚度

影响摆臂摆动阻力（附加侧倾刚度）和摆动方向的刚度。

非线性与迟滞

小变形软、大变形硬（限位），加载与卸载曲线不重合，多体模型中常用样条曲线 + 阻尼描述。

弹性中心：为什么同样的侧向力有的车 toe-in、有的车 toe-out

把车轮支架看作由两根横向连杆（含衬套）支撑的刚体。两根连杆的刚度对车轮形成一个弹性中心 xe = (k1x1 + k2x2)/(k1+k2)。侧向力作用线若通过弹性中心，车轮只平移不转动；若作用在弹性中心之后（例如轮胎拖距让接地点侧向力作用在轮心后方），车轮就会绕竖轴转动，产生前束变化：

ψ = Fy · K·(xF − xe) / (K·J − S²)　　K = Σki，S = Σkixi，J = Σkixi²

后悬设计中，工程师会通过前束连杆位置、衬套刚度差（例如前衬套软、后衬套硬）甚至专门的“被动转向”结构，让外侧后轮在侧向力和制动力下都产生 toe-in，从而提高高速稳定性和变道响应。保时捷 928 的 Weissach 后桥就是经典案例。

推荐建模步骤

  1. 硬点导入与校核：坐标系与试验一致（通常为整车坐标系），确认是设计载荷状态；左右对称检查。
  2. 纯运动学（K 模式）：所有衬套替换为理想运动副，检查自由度与冗余约束，先对标 Bump Steer、外倾、轮距等纯几何指标。
  3. 弹性运动学（C 模式）：恢复衬套（含方向、非线性曲线、预载），对标柔度指标；若偏差大，优先检查衬套局部坐标方向和刚度曲线来源。
  4. 柔性部件：扭力梁、副车架、稳定杆、控制臂等对柔度有明显贡献的部件，用模态缩聚生成柔性体替换（见 3.2 节）。扭力梁后悬必须用柔性体，否则侧倾刚度和侧倾转向完全失真。
  5. 边界条件匹配：制动柔度工况要锁止制动器、力作用在接地点；驱动工况力作用在轮心；转向盘锁止或自由要与试验一致；台架平台摩擦与补偿方式也要一致。
  6. 对标与优化：曲线逐条对标，提取指标误差，再进入灵敏度分析和硬点/衬套优化（2.9 节）。
K&C 仿真最常见的五类错误：① 衬套局部坐标系方向错，径向/轴向刚度对调；② 弹簧预载没调到设计位置，导致“零跳动”点偏移，曲线整体错位；③ 缓冲块间隙错误，大行程刚度突变位置不对；④ 制动柔度工况没锁止制动器或力加在轮心，制动力转向符号都可能反；⑤ 指标拟合区间、正负号约定与试验报告不一致，“看起来”偏差很大。

CHAPTER 3

车辆仿真扩展：从求解器到虚拟试验场

操稳与 K&C 只是车辆多体仿真的一部分。本章补齐支撑它们的理论（多体方程、求解器、柔性体、轮胎），并扩展到平顺性、制动、耐久、NVH、实时与联合仿真，以及决定仿真价值的模型对标。

3.1 多体动力学理论与求解器 高级

坐标选择

绝对坐标（笛卡尔坐标）法

每个刚体用质心位置 + 姿态（欧拉角/欧拉参数）描述，约束写成代数方程。方程规模大但稀疏、建模通用，Adams 等采用此类方法。

相对坐标（拓扑/递推）法

沿树形拓扑用关节相对坐标描述，坐标数接近自由度数，闭环需切断后加约束。方程规模小、效率高，Simpack 等采用此类思想。

运动方程：微分–代数方程（DAE）

M(q)·q̈ + ΦqT·λ = Q(q, q̇, t)　　（动力学方程）
Φ(q, t) = 0　　　　　　　　　　　（约束方程）

其中 q 为广义坐标，λ 为拉格朗日乘子（对应约束反力），Φq 为约束雅可比矩阵。这是一个 指标 3（index-3）DAE，直接积分容易漂移和不稳定，因此求解器会采用降指标（速度/加速度级约束）、约束稳定化（Baumgarte、GGL）或稳定化指标 2 公式（如 Adams 的 SI2）等技术。

分析类型

分析求解内容典型用途

刚性问题与积分器

车辆模型同时包含“慢”的车身运动（约 1 Hz）和“快”的衬套、轮胎高频模态（数百 Hz），这种时间尺度差异极大的系统称为刚性（stiff）系统。显式积分器的步长受最快模态限制，否则会发散；隐式积分器（BDF 类如 GSTIFF/WSTIFF，或 HHT-α、Newmark）每步要做牛顿迭代，但可以用大步长稳定地跨过高频成分。

积分器稳定性实验：一个“很硬”的衬套振子
单自由度振子 ẍ + 2ζωnẋ + ωn²x = 0，初始位移 1。黑色虚线为精确解。显式欧拉在无阻尼时任何步长都会发散；RK4 在 ωnh > 2.78 时发散；隐式欧拉恒稳定但有明显数值阻尼（振幅被“吃掉”）；梯形法恒稳定且不衰减但有相位误差。
求解器报“积分失败/校正器不收敛”时的排查思路：① 是否有不连续输入（阶跃、分段曲线拐点、接触突变）——改用光滑函数（如 STEP/STEP5 类函数）；② 是否有过硬的衬套或过小的质量（极高频模态）；③ 初始状态是否不平衡（先做静平衡）；④ 适当减小最大步长或放宽/收紧误差容差做对比；⑤ 检查单位制和样条曲线外推。

3.2 柔性多体 高级

当部件变形会显著影响运动学、载荷或振动时，需要把刚体换成柔性体：扭力梁（侧倾刚度和侧倾转向来自横梁扭转）、副车架、稳定杆、控制臂、车身（平顺性与 NVH）、钢板弹簧等。

浮动坐标系 + 模态叠加

工程上最常用的是浮动参考坐标系法（FFRF）：部件的大范围刚体运动由一个浮动坐标系描述，相对于该坐标系的小变形用若干模态叠加表示：

u(x, t) = Σi φi(x) · qi(t)（φi：模态振型，qi：模态坐标）

模态来自有限元模型的模态缩聚，最常用的是 Craig–Bampton 方法：把与其他部件连接的节点设为界面点，计算“固定界面主模态”（界面固定时的低阶振型）和“约束模态”（界面点逐个单位位移的静态变形形状），正交化后输出给多体软件（如 Adams 的 MNF、Simpack 的 FBI 文件）。

模态叠加：自由–自由梁的前四阶弯曲模态
各阶模态按各自固有频率振动（频率比 1 : 2.76 : 5.40 : 8.93），叠加后得到复杂的变形。模态截断就是只保留对结果有贡献的低阶模态。
  • 模态选择：保留频率覆盖关心激励频率 2–3 倍以上的模态；静态柔度（约束模态）对 K&C 和载荷精度至关重要，不能只保留几阶自由模态。
  • 模态阻尼：通常按频率分段给定（如 1%–5%），影响高频响应和稳定性。
  • 应力恢复：用模态应力叠加快速得到部件应力时间历程，直接用于疲劳分析。
  • 大变形：橡胶、钢板弹簧、线缆等大变形问题需要非线性有限元或绝对节点坐标法（ANCF）等方法。
  • 后处理动画：每帧节点位置 = 参考位置 + 刚体运动 + 模态叠加变形。多个网格源组合的柔性体要保证同一物理节点的所有渲染副本映射到同一组结果，缺失数据不能当作零位移处理，否则会出现“尖刺”或动画静止。

3.5 制动与纵向动力学 进阶

制动时前轴载荷增加、后轴载荷减少。若前后制动力分配固定，只有在某一个附着系数下前后轮会同时抱死，这个附着系数叫同步附着系数 φ0。

理想制动力分配（I 曲线）：Fμ1 = φG(b + φhg)/L，Fμ2 = φG(a − φhg)/L
固定比例分配（β 线）：Fμ2 = Fμ1·(1 − β)/β　　同步附着系数：φ0 = (Lβ − b)/hg（a、b：质心到前、后轴距离）
  • φ < φ0：前轮先抱死——车辆失去转向能力，但方向稳定；
  • φ > φ0：后轮先抱死——车辆可能甩尾，非常危险。因此设计时让常用路面的 φ 小于 φ0，并用 ABS/EBD 电子调节。
制动力分配：I 曲线、β 线与同步附着系数
轴距固定 2.7 m。I 曲线上的刻度点表示对应附着系数下的理想分配；β 线与 I 曲线的交点即同步附着系数。制动效率 = 制动强度 / 利用附着系数，越接近 100% 越好。

纵向动力学的其他仿真主题

  • 制动点头与车身俯仰：与 2.4 节抗点头几何直接相关；
  • 制动跑偏：左右制动力不一致、主销偏移距、制动力转向柔度共同作用；
  • 驱动扭矩转向（Torque Steer）：前驱车左右半轴夹角/长度不等、轮心偏距导致加速时方向盘被拉偏；
  • ABS/ESC/TCS 联合仿真：多体模型 + 控制器（Simulink/FMU），评估制动距离、横摆稳定、控制介入时机。

3.7 NVH 与动力总成悬置 高级

多体仿真在中低频 NVH（一般在 0–50 Hz 量级）中应用广泛，最经典的是动力总成悬置系统设计：

  • 六自由度模态与解耦：动力总成作为刚体，悬置作为三向弹簧，计算 6 阶刚体模态。各阶模态在主方向上的能量占比（解耦率）越高越好，常见目标是主要方向（垂向、绕曲轴的侧倾）达到约 85%–90% 以上。
  • 频率配置：刚体模态频率应低于怠速点火频率的 1/√2 以实现隔振，同时高于路面激励敏感频段并与车身、悬架模态错开。
  • 扭矩轴（TRA）布置：悬置弹性中心布置在扭矩轴附近，使发动机扭矩波动主要激起绕扭矩轴的转动，减少耦合。

  • 对标顺序由底向上，避免在整车层面用错误参数“凑”结果；
  • 变更管理：模型版本、参数版本和结果一一对应，便于复现与审核。
“曲线对上了”不等于“模型对了”。用一个错误参数抵消另一个错误参数，单一工况可以对得很好，但换一个工况（例如低附着、满载）就会完全失效。多工况、多层级交叉对标才能建立真正的可信度。
