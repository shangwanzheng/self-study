ALE 绳索单元 vs 梁单元：原理、可视化与工业软件设计调研

本报告由浅入深回答三个问题：① 绳和梁在力学上到底差在哪；② "ALE（任意拉格朗日-欧拉）"给绳索单元带来了什么，方程长什么样；③ LS-DYNA、Abaqus、Ansys、Radioss、Code_Aster、Adams、MotionSolve、Simpack、RecurDyn、AGX、Vortex、OrcaFlex、Exudyn、Chrono 等软件分别怎么设计梁单元与绳索/滑轮。文中动画全部由页面脚本实时绘制，不使用 GIF，无外部依赖，可离线打开；大部分动画可交互（拖动滑块、切换模式）。

0结论速览

一句话

梁单元描述"会弯、会扭、能受压"的杆件；ALE 绳索单元描述"只受拉、几乎不抗弯、材料在滑轮和卷筒之间不断流动"的绳。两者的差别同时出现在力学模型和运动学描述两个层面。

力学层面：拉硬压软

梁同时具备轴向 EA、弯曲 EI、扭转 GJ（Timoshenko 梁还有剪切 κGA）刚度，可承受拉、压、弯、扭、剪。绳以 EA 为主，EI 很小或忽略，一受压就松弛。Escalona 把绳、带、链这类"受拉很硬、受压很软"的构件称为 uni-rigid solids。

运动学层面：节点不再是材料点

常规梁单元和绳单元都是拉格朗日网格，节点永远绑定同一个材料点。ALE 绳索单元给每个节点增加一个物质坐标 s（未拉伸弧长）作为未知量。节点可以固定在滑轮切点让材料流过，也可以随吊钩运动，或者随材料运动。

为什么值得做

拉格朗日网格里任何一段绳迟早都会绕上滑轮，所以整根绳都必须按包角分辨率加密。ALE 只需在切点和包角处布置节点，跨中用粗单元，单元数通常可下降 1～2 个数量级（§5.2 有估算器），而且不用做绳-滑轮接触检测（Peng 2017；Escalona 2017）。

工业现状

通用 FEA 用"材料流自由度 / 滑轮单元"做工程化近似：LS-DYNA *ELEMENT_BEAM_PULLEY、Abaqus SLIPRING、Radioss 滑轮弹簧、Code_Aster CABLE_POULIE。MBD 商软以"无质量绳力元 + 离散刚体段 / 非线性梁 + 接触"为主（Adams、Simpack、RecurDyn、MotionSolve）。连续 ALE 绳索有限元在本次公开资料检索范围内，只见于开源 Exudyn（二维、全部单元共享一个欧拉坐标）和学术成果（Escalona、任革学、齐朝晖、彭云等团队）。

给 V1.3.030 的建议

采用"节点物质坐标"型的任意 ALE 搭配 ANCF 绳索单元。节点分为固定端、弹性端、滑轮切点、卷筒、自由节点几类；摩擦作为作用在 s 上的广义力；线性约束先做坐标缩减。分阶段推进：力元 → 平面 ALE → 空间与摩擦 → 拉扭耦合与一跨一单元（§5）。

1入门：绳和梁，到底差在哪

1.1 生活直觉

拿一根钢管和一根同样长的钢丝绳做几个动作，差别一目了然：

动作梁（钢管、吊臂、传动轴）绳（钢丝绳、皮带、电缆）
推一端顶得住；压力超过临界值才失稳（屈曲）立刻软塌，几乎传不了压力
一端固定、水平伸出只轻微下挠直接垂下来
两端挂起下挠量由弯曲刚度决定落成悬链线（形状只由重力和张力决定）
绕过滑轮需要很大弯矩，局部会屈服顺从地包住滑轮；包角上的张力按摩擦呈指数变化
扭转有扭转刚度 GJ通常忽略；钢丝绳存在"拉-扭耦合"，受拉会自转
在滑轮组里运动不涉及材料持续流过滑轮切点；不同跨段的轴向速度可以不同

下面是一个实时力学实验：左边是绳（EI=0），右边是梁（EI 由滑块控制）。两者长度、线密度、重力完全相同，唯一的区别是弯曲刚度。

1.3 两个关键参数

参数一：无量纲弯曲刚度 λ。它比较的是"自重想把构件压弯"和"弯曲刚度不让它弯"这两件事。λ≪1 时构件表现得像绳，λ≫1 时像梁；图 1 的滑块调的就是它。

(1) λ=EIρAgL3,ℓb=EIT

参数二：弯曲边界层长度 ℓb。带张力 T 的细长构件满足 EI·w⁗ − T·w″ = q，齐次解含 e±x/ℓb。也就是说，弯曲只在夹持端、滑轮入绳点和出绳点附近长度约为 ℓb 的"边界层"里起作用，其余部分按弦（纯绳）的规律工作。示意估算：取等效 EI≈100 N·m²、T=50 kN，得 ℓb≈4.5 cm，远小于起重机械中数米到数十米的跨距。

这正是 ALE 网格"跨中粗、切点细"的力学依据。自由跨段可以按绳处理，粗单元甚至一跨一个单元（Escalona 的 ALEM 就是这样做的）；需要分辨弯曲的只有切点附近。如果网格固定在材料上（拉格朗日），切点处的边界层会沿着绳不断移动，只能全长加密。

3深入：ALE 绳索单元原理

3.1 拉格朗日、欧拉与 ALE

连续介质力学有三种描述方式。拉格朗日描述中节点就是材料点，适合固体，但材料一旦大范围流动，网格就会被"冲走"，只能不断重划分。欧拉描述中节点固定在空间，材料从中流过，适合流体，但很难跟踪运动的边界（例如吊钩）。ALE 描述中网格的运动可以"按需"指定：一部分节点取拉格朗日，一部分取欧拉，其余随某个物体运动，或者按网格质量要求移动。

用速度来描述三者的差别最简洁：设材料速度为 v、网格速度为 v̂，则对流速度 c = v − v̂。拉格朗日对应 c = 0；欧拉对应 v̂ = 0；ALE 中 v̂ 任意。对一维的绳，"对流"就是材料沿绳轴相对节点的流动，它的量值正是节点物质坐标的变化率 ṡ（量纲为长度/时间）。

3.3 两大流派：共享欧拉坐标 vs 节点物质坐标

3.4 节点类型与约束

节点物质坐标型 ALE 的精髓是：节点本身都一样，节点"是什么"由约束决定。Peng（2017）给出最基本的两种退化：欧拉节点施加 𝒓 − 𝒓₀ = 0，拉格朗日节点施加 s − s₀ = 0。Escalona（2022）把滑轮组里的节点归为四类：连续节点、固定节点、弹性支座节点、与滑轮或卷筒相切的节点。把鼠标移到右侧列表上，可以在图中高亮对应节点。

约束处理的两个经验（Escalona 2017/2022）：

  • 切点位置约束、物质坐标连续性约束、不打滑约束都是线性的，可以系统地消去（坐标缩减），得到 ṗ = B(qRB)q̇ + D(t) 的速度变换。
  • 如果忽略滑轮转动惯量，滑轮处需要一个力矩平衡的非线性约束；如果把滑轮转角作为广义坐标，用"绳-滑轮不打滑"的线性约束代替它，系统方程就从 DAE 变成 ODE，既更准（计入转动惯量），也更好解。

3.5 滑轮包角段与摩擦

包角段（绳缠在滑轮上的那段）有三种处理方式：

  1. 不建模包角段（Escalona ALEM）：两侧单元的端节点分别约束在两个切点上，中间用物质坐标连续性 sout − sin = Rθw 跨过去，并假设不打滑。前提是切点位置事先已知，这对大多数起升系统都成立。
  2. 过渡单元（Peng, Wei & Zhou 2017）：用一个两端都固定在滑轮上的 ALE 单元表示接触段，摩擦按"张力衰减"规律分布在过渡单元上；推导表明摩擦只产生作用在弧长坐标上的广义力，与节点位置和方向无关。滑轮远小于绳长时，过渡单元可以退化成一个 ALE 节点。
  3. 包角段用欧拉节点细分 + 接触/摩擦（Pechstein & Gerstmayr 2013 的皮带传动）：自由跨用粗网格，接触区用细网格，可以研究接触区内的滑移分布。

3.7 数值实现要点（踩坑清单）

  1. 构型相关质量阵与二次速度项：显式积分每步都要重算 M(q) 和 𝑸v；隐式积分（广义-α、HHT）需要对 𝑸v 做线化。
  2. 1/l 奇异：形函数和对流项里含 1/l，必须给出 lmin，并配合节点合并或交换（LS-DYNA 在未拉伸长度小于 lmin 时把短单元"swap"到滑轮另一侧）。
  3. 刚性：钢丝绳的 EA/EI 极大，轴向模态频率很高。要么用隐式积分，要么滤波：齐朝晖等（2017）用短时间内的"时间平均轴向应变"代替瞬时应变，滤掉高频分量。
  4. 拉压非光滑：松弛时（T<0）轴向刚度应趋于 0，刚度突变需要正则化或互补处理。
  5. 摩擦粘滑：摩擦作用在 s 上；粘着态退化为约束 ṡ = Rφ̇，滑移态是力；可用正则化库仑或 LCP。
  6. 约束大多线性：切点、连续性、不打滑约束都可以坐标缩减；只保留少量非线性约束，例如忽略滑轮惯量时的力矩平衡。
  7. 切点几何：三维中有滑轮偏角（fleet angle）、多层缠绕、切点漂移等问题；ALEM 假设切点位置已知。
  8. 初始化：要先做预张力和静平衡找形（Li 等 2023 先求静平衡构型作为动力学初值；Code_Aster CABLE_POULIE 正是用于架空线放线的静力找形）。
  9. 能量一致性：Escalona 的综述指出，纯"变长度弹簧"模型可能在能量上不一致；ALE 列式要把物质边界上的通量算对。
  10. 后处理：节点不再是材料点，结果中必须同时输出 s(t)。绳表面纹理与标记、疲劳计数（例如绕过滑轮的弯曲次数）都要按物质坐标映射。

4.3 五种设计范式

把上面这些设计归纳一下，"绳过滑轮"在工业界有五种范式：

范式核心思想代表长处局限
P1 无质量力元绳 = 沿几何路径的弹簧或约束Adams Simplified、Simpack FE 246、Exudyn ReevingSystemSprings、Simscape、MuJoCo tendon、OrcaFlex 绞车钢丝绳极快、稳健、易用没有绳惯性和横向振动；纯弹簧模型可能能量不一致（Escalona 引文）
P2 拉格朗日离散 + 接触绳 = 细网格（刚体段、梁或 ANCF）+ 滑轮接触Adams Discretized、RecurDyn FFlex、MotionSolve/Chrono ANCF + 接触物理最完整、通用全长细网格，接触刚性大，慢且对参数敏感
P3 材料流力元 / 滑轮单元在滑轮或滑环处让未拉伸长度在单元间转移LS-DYNA BEAM_PULLEY、Abaqus SLIPRING、Radioss TYPE12/28、Code_Aster CABLE_POULIE免接触、实现简单，与显式求解器契合滑轮是一个点，没有包角几何；跨内动力学取决于两侧单元
P4 自适应集中参数 + 滑动接触节点动态增删节点 + 非物质接触节点AGX Wire、Vortex Adaptive Cables实时，高张力下稳定精度让位于速度，没有有限元意义下的收敛性
P5 连续 ALE 有限元节点物质坐标为未知量Exudyn ALEANCFCable2D、Escalona ALE-ANCF/ALEM、Peng、齐朝晖粗网格也能高精度，天然支持变长度，摩擦作用在 s 上列式与实现复杂：构型相关质量阵、l→0、网格运动设计

5对 V1.3.030 的启示与建议

5.1 推荐技术路线

  1. 运动学：采用节点物质坐标型 ALE（Hong & Ren / Escalona），不用"共享欧拉坐标"型。原因是起升、电梯、滑轮组都属于非形状保持机构，各跨轴向速度不同（§3.3 的 4:1 例子）。
  2. 变形描述：先做 ANCF 梯度缺省绳，节点取 𝒓、𝒓′、s。保留一个小的 EI，既能得到光滑形状，也起到数值正则化作用。需要折线绕滑轮时，允许斜率间断（Peng 2017 的 𝒓、s 节点）。
  3. 滑轮：切点节点（位置约束 + 物质坐标连续性），包角段默认不建模（Escalona）。需要包角内的张力分布时，用过渡单元（Peng 2017）。摩擦作为 s 上的广义力，按绞盘方程判断粘着或滑移。
  4. 约束：线性约束先坐标缩减。把滑轮转角作为广义坐标，用不打滑的线性约束代替力矩平衡，得到 ODE 而不是 DAE（Escalona 2022）。
  5. 网格管理：给 s 设 lmin/lmax，超限时合并或插入节点（参考 LS-DYNA 的 swap、OrcaFlex 的节点激活）。卷筒出绳点为欧拉节点。
  6. 后续扩展：三维 + 拉-扭耦合（Escalona 2017 引入局部截面扭转角）；长跨用 ALEM 一跨一单元，适合实时仿真和大系统。

5.2 单元规模估算

拉格朗日网格中每一段绳都可能经过滑轮，单元长度只能取 Δs = R·Δθ（Δθ 是包角分辨率），并且全长都要满足；ALE 只需要"跨数 × 每跨单元数 + 包角单元"。下面的估算器按这个逻辑算单元数和自由度（拉格朗日 ANCF 每节点 6 个，ALE-ANCF 每节点 7 个，三维）。

5.5 对数据模型与前后处理的影响

  • 已有基础：客户端 ADM 解析已支持 Adams BEAM（I/J marker、截面参数、FORMULATION）和 FE_PART（节点、坐标矩阵、截面矩阵、初始条件矩阵），对应 PSAdmData::Beam 与 PSAdmData::FEPart。
  • 需要新增的数据实体：绳截面与材料（EA、EI、ρA，可选拉-扭耦合系数）；节点类型与初始 s；滑轮和卷筒（半径、所属刚体、转动自由度、摩擦系数）；缠绕顺序与方向；绞车驱动（收放速度、长度或张力控制）。
  • 结果输出：除节点位置外，还要输出 s(t)、各跨张力、滑移速度、包角。
  • 渲染：节点不是材料点，绳的纹理和标记必须按 s 映射，否则看起来像"纹理跟着网格走"，与真实材料运动不符（对比图 0 中材料标记的流动）。张力云图沿 s 着色；卷筒上的绳圈数由 s₀ 推算。
  • 与 Adams 模型互通：Machinery Cable 的 Simplified 方法在概念上对应力元型绳，Discretized 方法对应离散刚体段；具体映射关系需要结合 ADM 中的实际语句再做评估。
