M1 · L1

从 clone 到打开页面

git clone <仓库地址>
cd ps-cae-cloud-space-frontend
npm install          # 按 package-lock.json 装依赖
npm start            # package.json 里是 craco start

终端出现本地地址后，打开 http://localhost:8000。端口在 craco.config.js 的 devServer.port。地址栏路径就是路由，例如 /workbench、/login。能打开登录页，即算跑起来。

仓库 README 写 yarn，锁文件是 package-lock.json，课堂用 npm。

M1 · 概念卡

样式：看见这个词，它是哪一类

Less 和 Sass 是一类。CSS Modules 是另一类，经常和 Less 写在同一个文件里。

看见它是同类还有本仓
.less预处理器：变量、嵌套、混入，编译成 CSSSass / SCSS、Stylus改样式先看同名 less
CSS Modules类名只在当前组件生效Vue 的 scoped和 Less 一起用
antd token设计令牌：颜色、字号、间距CSS 变量和 less 一起决定长相
PostCSS后处理：加前缀、压缩Autoprefixer构建链里，不手写
CSS-in-JS / 工具类样式写在 JS 里，或用类名拼界面styled-components、Tailwind本仓不用
Less 解决「CSS 怎么写」。CSS Modules 解决「类名别串到别的组件」。

M2 · L2

推荐 Prompt（当场念一遍）

【现象】页面 /xxx 上，「……」不符合预期（或把控制台报错贴在这里）。
【我已看到】地址是 /xxx；routeConfig 指向 src/pages/.../Xxx.tsx。
【请只做定位】指出最可能要看的文件和函数，并给出依据
（文案 key、接口 path 或组件名）。
【不要】改代码，不要重构。
先 @ routeConfig 和该页目录，再用 Chat 问。定位阶段不用 Agent 改文件。要改一小处时，把「请只做定位」换成一句具体改动。
