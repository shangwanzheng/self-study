14.1 整车模型的组成与数据准备

前面各章分别讲了多体基础、子系统、悬架、五连杆、弹性元件、轮胎、转向、K&C 和操稳理论。整车仿真就是把这些“零件”按真实车辆的连接关系装成一辆虚拟样车（virtual prototype），让它在虚拟路面上由虚拟驾驶员驾驶，再把输出和试验对比。本节先回答两个最朴素的问题：整车模型由什么组成？建一辆车到底要准备哪些数据、这些数据可信到什么程度？

整车模型是什么：从“子系统集合”到“虚拟样车”

在 Adams/Car 一类模板化软件里，整车装配（full-vehicle assembly）不是一个巨大的单一模型，而是若干子系统（subsystem）加一个试验台（test rig）的组合：前悬架、后悬架、转向、前后稳定杆、车身、动力总成、制动、四个车轮（含轮胎）各是一个子系统，它们通过通讯器（communicator）在装配时自动连接（模板、子系统、通讯器的概念见 第 3 章 模板、子系统与装配）。装配完成后，整车模型通常包含几十个刚体部件、上百个运动副和衬套、若干力元和四个轮胎模型，系统自由度从几十到上百个不等——衬套越多、柔性体越多，自由度越多。

和真车相比，整车多体模型保留了对车辆动力学最重要的东西：部件的质量与惯量、悬架与转向的空间几何、弹簧/减振器/衬套/缓冲块的非线性特性、轮胎力学、载荷转移和大位移运动学。它通常省略或简化的是：车身的结构弹性（需要时用柔性体补上，见 第 6 章）、发动机燃烧与传动系扭振细节、电子控制器的完整逻辑（需要时通过联合仿真接入，见 14.9 节）。这也正是第 2 章“模型层级”的最高一层：二自由度模型只有侧向和横摆，课程的非线性整车模型 VMD.veh.Vehicle 增加了侧倾、载荷转移、非线性轮胎和等效 K&C，而完整的多体整车模型把每个衬套、每根连杆都显式建出来。

要点：整车仿真 = 模型 + 输入 + 设置 + 解读

同一个整车模型，换一个驾驶员参数、换一个输出步长、换一种滤波方法，得到的“指标”可能差 10% 以上。所以整车仿真的质量不只取决于模型本身，还取决于输入（路面、驾驶员、事件）、求解设置和后处理。本章把这四件事放在同等重要的位置来讲。

数据来源与成熟度

同一项数据在项目的不同阶段有不同的“可信度”。概念阶段的衬套刚度可能只是参考上一代车型估的，样件阶段才有台架实测值，量产前还会因为供应商调整再变一次。工程上常把数据成熟度（data maturity）分成几级，并在模型里逐项标注：

估计值

经验公式、文献典型值、工程师判断。只能用于方向性判断和方案比较。

对标车 / 上一代

来自相似车型的实测数据。量级可信，细节（如衬套方向、曲线形状）未必适用。

设计值 / 规格

CAD 硬点、供应商规格书。几何通常可信，特性曲线是“目标值”而非实测。

零件 / 整车实测

台架实测的特性曲线，整车称重、K&C 与操稳试验。可以用于定量结论和对标。

数据成熟度决定了结论能说到多“硬”。用估计数据跑出“不足转向度 2.23 °/g”，正确的表述是“在当前假设下约 2.2 °/g，主要不确定性来自前悬衬套和轮胎数据”，而不是一个精确到小数点后两位的承诺。一份合格的仿真报告应附带数据清单及每项的来源与版本（14.7 节、14.10 节）。

避坑：用早期估计数据给出“精确”结论
概念阶段的模型里，轮胎用的是对标车的 .tir，衬套是估计值，却把仿真结果当成目标达成的证据，在评审会上报“横摆响应时间 0.135 s，满足目标”。 结论的精度不能高于输入数据的精度。早期模型适合做相对比较（方案 A 比方案 B 好多少、趋势如何），绝对值要等关键数据（轮胎、衬套、转向柔度）有了实测值、并完成对标后才能作为判定依据。报告里要写清每项关键数据的成熟度，并对影响最大的几项做灵敏度分析（14.8 节），给出结论的不确定范围。
易错：轮胎文件“拿来就用”
找到一个同规格的 .tir 文件就直接装上，不看它的测试条件。 轮胎模型参数是在特定充气压力、载荷范围、速度和试验表面上测得并拟合的，文件里通常写明了适用的载荷、侧偏角、滑移率范围。超出范围外推（例如用轻载数据算满载、用干路数据算湿路）结果会失真；气压不同、磨损程度不同，侧偏刚度可以差 10% 以上。装配前先读文件头部的单位段和适用范围（第 7 章），并确认与试验车的轮胎规格、气压一致。

14.2 整车装配与质量校核

装配成功只说明“零件拼上了”，不说明“拼对了”。整车装好后的第一件事不是跑工况，而是核对它和真车是不是同一辆车：质量、轴荷、质心高、转动惯量逐项对账。第 3 章已经讲过车身质量的口径和重复计入的后果，本节在整车层面讲校核的流程：查什么、怎么测、差了怎么改。

子系统组装与整车试验台

整车装配由“一组子系统 + 一个整车试验台”组成。试验台提供驾驶机器（方向盘、油门、制动、挡位的执行机构）和工况接口，车身在试验台中有完整的 6 个自由度。装配时软件按通讯器名称和类型把子系统连起来，并给出一份装配报告：哪些通讯器匹配上了、哪些没有匹配。整车装配的验收清单（通讯器、质量、簧上/簧下、自由度、静平衡、零时刻、数据一致性）见第 3 章表 3-9，这里不再重复，只强调两条整车层面的经验：

  • 未匹配通讯器要逐条“销账”。整车装配里常见的允许未匹配项是那些本来就不用的接口（例如本车没有的四驱扭矩输入）；凡是与安装（mount）有关的未匹配，都意味着某个部件被自动接到了大地上，模型能算，但结果全错。
  • 装配报告要存档。它是“这个模型由哪些版本的子系统组成”的唯一凭证，对标或复现结果时会用到（14.10 节）。

质量属性校核的四个层次

质量属性（mass properties）的校核可以分成由粗到细的四个层次。每一层都能发现上一层发现不了的错误，所以不能停在第一层：

  1. 总质量与簧上 / 簧下划分。总质量对得上只是起点；簧下质量要单独核对，因为它决定车轮跳动频率和轮胎动载荷，而总质量里少算的簧下质量可能恰好被多算的簧上质量抵消。
  2. 轴荷与轮荷。前后轴荷比例决定质心纵向位置 \(a\)、\(b\)，进而决定不足转向的“质量项”；左右轮荷差反映横向质心偏置（驾驶员、电池、油箱）。
  3. 质心高度。侧向、纵向载荷转移都与 \(h\) 成正比，侧倾力矩也与簧上质心到侧倾轴的距离成正比。质心高错 20 mm，载荷转移就错约 4%。
  4. 转动惯量。\(I_{zz}\) 决定横摆响应的快慢，\(I_{xx}\) 决定侧倾动态，\(I_{yy}\) 决定俯仰与平顺性中的俯仰模态；乘积惯量 \(I_{xz}\) 影响侧倾与横摆的耦合。

“总质量 1600 kg、前轴荷 57.1% 都和称重一致，质量校核通过。” 总质量和轴荷只约束了质心在水平面内的位置，完全不约束质心高度和惯量。一个部件的高度坐标填错（例如车身质心用了白车身 CAD 值），总质量和轴荷一点不变，质心高却能差二三十毫米；车身自身惯量沿用模板默认值，质量全对，\(I_{zz}\) 却能差 10% 以上。质心高直接进入载荷转移和侧倾力矩，\(I_{zz}\) 直接决定横摆响应时间，这两项必须单独核对——演示 B 里有两个这样的例子。

质心高度怎么测：倾斜法

质心纵向位置用四轮秤一次就能测出，质心高度却要“让车倾斜”才能测。最常用的是倾斜法（axle-lift method）：先在水平状态称出前轴荷，再把后轴抬高，使车辆纵向倾斜角为 \(\theta\)，重新称前轴荷。质心越高，倾斜后重量向前轴“滑”得越多。对倾斜状态取力矩平衡可得：

\[ h = r_s + \frac{L\,\Delta F_{zf}}{m g\,\tan\theta} \](14-1)
  • \(r_s\)：轮心静载高度（m）；\(L\)：轴距；\(\Delta F_{zf}\)：倾斜后前轴荷的增量（N）；\(mg\)：整车重力；\(\theta\)：车辆纵向倾斜角
  • 推导时假设倾斜过程中悬架不变形、燃油等液体不流动、轮胎接地点仍在轮心正下方
算例 14-1：倾斜法测质心高，以及它对秤精度有多敏感

示例车 \(mg = 15\,696\ \mathrm{N}\)，\(L = 2.8\ \mathrm{m}\)，取轮心静载高度 \(r_s = 0.30\ \mathrm{m}\)（教学假设），后轴抬起使 \(\theta = 15^\circ\)（\(\tan\theta = 0.2679\)）。若真实质心高 \(h = 0.55\ \mathrm{m}\)，前轴荷增量应为

\(\Delta F_{zf} = \dfrac{mg\,(h-r_s)\tan\theta}{L} = \dfrac{15\,696\times0.25\times0.2679}{2.8} \approx 375.5\ \mathrm{N}\)，即前轴荷从 8969 N 增加到约 9345 N。

反过来，由式 (14-1)：\(h = 0.30 + \dfrac{2.8\times375.5}{15\,696\times0.2679} = 0.30 + 0.250 = 0.550\ \mathrm{m}\)。

灵敏度：\(\dfrac{\partial h}{\partial \Delta F_{zf}} = \dfrac{L}{mg\tan\theta} \approx 0.67\ \mathrm{mm/N}\)。也就是说，前轴秤读数差 10 N（不到轴荷的 0.12%），质心高就差约 6.7 mm；若只抬到 \(5^\circ\)，灵敏度变成约 2.0 mm/N，误差放大 3 倍。所以倾斜法要抬得足够高（常见 10°–20°），秤要精确，悬架要锁止（减振器换刚性支撑或用限位块顶死），燃油加满或抽空，避免液体流动和悬架变形带来的系统误差。

工程经验：称重状态必须与模型状态一致

对账之前先对“状态”：燃油是满箱还是半箱？驾驶员和仪器是否在车上、坐在哪里？备胎、随车工具、玻璃水是否在车上？轮胎气压是多少？四轮秤是否在同一水平面上？同一辆车，满箱与空箱差 40 kg 左右，驾驶员 75 kg 坐在左前位置会让左前轮荷明显增加。称重记录要附上这些状态，模型里的“试验配载”要逐项对应。称重最好重复 3 次，每次之间让车前后滚动一下再停稳，以消除轮胎和衬套的迟滞。

转动惯量：平行轴定理与惯量测量

模型的整车惯量由各部件的“自身惯量”加上“质心偏离整车质心带来的附加项”组成，这就是平行轴定理（parallel axis theorem）。以整车质心 \(G\) 为原点：

\[ I_{zz}^{G}=\sum_i\Big[I_{zz,i}+m_i\big((x_i-x_G)^2+(y_i-y_G)^2\big)\Big],\qquad I_{xx}^{G}=\sum_i\Big[I_{xx,i}+m_i\big((y_i-y_G)^2+(z_i-z_G)^2\big)\Big] \](14-2)
  • \(I_{zz,i}\)、\(I_{xx,i}\)：部件 \(i\) 绕自身质心、平行于整车坐标轴的惯量；\((x_i,y_i,z_i)\)：部件质心坐标
  • \(I_{yy}^{G}\) 同理，用 \((x_i-x_G)^2+(z_i-z_G)^2\)；乘积惯量 \(I_{xz}^{G}=\sum_i[I_{xz,i}+m_i(x_i-x_G)(z_i-z_G)]\)（符号约定各软件不同，以文档为准）

偏差的修正方法：先查来源，再修车身

模型和实测对不上时，最省事的做法是改车身部件：车身是唯一一个“包含了所有没单独建模的东西”的部件，改它的质量、质心和惯量总能把总数凑上。若其他部件都已确认无误，只改车身是合理的，修正量由目标值直接算出：

\[ m_b' = m_T-\sum_{i\ne b}m_i,\qquad x_b' = \frac{m_T\,x_T-\sum_{i\ne b}m_i x_i}{m_b'},\qquad z_b' = \frac{m_T\,h_T-\sum_{i\ne b}m_i z_i}{m_b'} \](14-3)
  • 下标 \(T\) 表示实测（目标）值；\(x_T\) 由实测前轴荷换算：\(x_T = L\,F_{zf,T}/(m_T g) - L/2\)

但这一步必须放在最后。正确的顺序是：

  1. 核对定义与状态：称重状态（燃油、驾驶员、仪器、备胎）与模型配载一一对应；单位、坐标原点、方向一致（第 2 章、第 3 章）。
  2. 排查重复与遗漏：逐个部件对照 BOM 和子系统清单，特别是车轮、制动器、副车架、稳定杆这些“归属模糊”的部件。
  3. 单独核对簧下质量：簧下部件可以拆下来单独称，必须与模型逐项一致。
  4. 最后才修正车身：用式 (14-3) 修正车身质量与质心，用实测惯量反推车身自身惯量。
  5. 重做静平衡并复查：车身高度、四轮轮荷与设计值、称重值对比（14.3 节）。
避坑：质量重复计入或遗漏，在整车层面才暴露
每个子系统单独看都“合理”，装成整车后总质量多出几十公斤，就把车身质量减掉同样的数。 子系统往往由不同人建、取自不同来源，重复计入（车身质量已含动力总成或燃油，又单独建了部件）和遗漏（试验仪器、驾驶员、备胎）在单个子系统里看不出来，装配后才在总数上露出来。总数差多少只是症状，要按 BOM 逐项找到是哪个部件重复或遗漏，从源头改掉。尤其要先确认偏差落在簧上还是簧下——若多出来的是车轮质量，减车身质量会让簧下质量偏大、簧上质量偏小，偏频和车轮跳动频率都会错。

14.3 静平衡与初始化

整车模型是在“设计姿态”下搭建的：硬点坐标、弹簧安装长度、衬套零位都对应某一个设计载荷状态。仿真开始那一刻，如果模型的受力并不平衡、各部件的速度也互相矛盾，积分器会忠实地把这种不平衡“演”成一段瞬态，而这段瞬态与驾驶输入毫无关系。本节讲两件事：静平衡（static equilibrium）把模型放到力平衡的位置，动力学初始化（initialization）给所有部件一组互相协调的初速度。最后用演示 C 看初始化出错时结果会被污染成什么样。

设计姿态、静平衡姿态与初始条件

先区分三个容易混在一起的“姿态”：

设计姿态

design position。硬点、构造框所在的几何位置，通常对应某个设计载荷（如“整备质量 + 若干乘员”）。模型在这个姿态下“画”出来，弹簧、衬套在这里的变形和预载由属性文件和安装参数决定。

静平衡姿态

static equilibrium position。在当前质量、配载和重力作用下，所有力和力矩平衡、各部件速度为零的位置。配载与设计载荷不同、弹簧预载设置不当时，它与设计姿态相差几毫米到几十毫米。

动力学初始状态

initial conditions。动力学积分起点的位置和速度。正确做法：位置取静平衡姿态，速度取“整车以 \(v_0\) 匀速直线行驶”时各部件应有的速度（车身 \(v_0\)，车轮转速 \(v_0/r_e\)）。

静平衡在数学上就是令运动方程中所有速度、加速度为零，求解一组非线性代数方程：

\[ \boldsymbol{\Phi}_{\mathbf q}^{T}(\mathbf q)\,\boldsymbol\lambda = \mathbf Q(\mathbf q),\qquad \boldsymbol\Phi(\mathbf q) = \mathbf 0 \](14-4)
  • \(\mathbf q\)：广义坐标；\(\boldsymbol\Phi\)：约束方程，\(\boldsymbol\Phi_{\mathbf q}\) 为其雅可比矩阵；\(\boldsymbol\lambda\)：拉格朗日乘子（对应运动副约束反力）；\(\mathbf Q\)：重力、弹簧、衬套、轮胎垂向力等广义力
  • 一般用牛顿—拉弗森迭代求解（第 1 章），初值就是设计姿态。设计姿态离平衡位置越远、模型非线性越强（缓冲块接触、衬套刚度突变），越容易不收敛

静平衡在多体软件里常被叫作“settle”。整车静平衡有一个细节：车辆静止在水平路面上时，纵向、侧向和横摆方向只靠轮胎摩擦约束，数值上可能漂移，所以软件通常在静平衡期间临时约束车身的部分自由度或锁住转向（具体选项以软件文档为准）。静平衡的物理意义和载荷提取在 第 10 章 静载荷与载荷分解 中有详细讨论，这里关注它在整车流程中的角色：它是所有动力学工况的起点。

算例 14-3：车身比平衡位置高 35 mm 时会发生什么

设模型的前悬弹簧预载是按较轻的设计载荷设置的，静平衡计算得到车身前部下沉 35 mm、后部下沉 20 mm（教学假设，与演示 C 一致）。若跳过静平衡、直接从设计姿态开始动力学：

① 释放瞬间，前悬单侧弹簧力比平衡值小 \(k_w\,\Delta z = 23\ \mathrm{N/mm}\times35\ \mathrm{mm}\approx805\ \mathrm{N}\)，后悬单侧小 \(23.5\times20=470\ \mathrm{N}\)，簧上质量得到向下的净力，开始下落。

② 车身以簧上偏频（前 1.14 Hz、后 1.34 Hz，见第 4 章）振荡，阻尼比约 0.3，每个周期幅值衰减到约 \(e^{-2\pi\zeta/\sqrt{1-\zeta^2}}\approx0.14\)。按演示 C 的半车模型，前轮单轮轮荷在 3552–4872 N 之间摆动（静载 4485 N，最低处 −20.8%），0.97 s 后前后轮荷才回到 ±2% 以内。

③ 如果在 t = 0.5 s 就开始角阶跃，此后半秒内轮荷仍有约 6% 的偏差。侧偏刚度随轮荷变化、载荷转移和侧倾零点都被这段“假瞬态”改变，测得的响应时间和超调量就不再只是车辆本身的特性。

避坑：没做静平衡就开始动态仿真
模型能算就直接跑角阶跃，或者为了省时间把静平衡关掉；看到前 1 s 的曲线有起伏，以为是“车辆刚开始的正常反应”。 不做静平衡时，车身从设计姿态“掉”到平衡位置的过程会叠加在工况响应上，表现为 1–1.5 Hz 的车身跳动与俯仰、轮荷起伏和侧倾零点漂移。每个动力学工况都应以静平衡（或带初速度的准静态平衡）为起点。静平衡不收敛时要找原因——设计姿态离平衡位置太远、弹簧预载或自由长度错误、缓冲块一开始就接触、冗余约束——而不是把它关掉。

工程经验：正式工况之前先做“零输入体检”

静平衡之后、正式工况之前，先跑一个“零输入直线”：以目标车速匀速直行 2–3 s，方向盘固定在零位，不加任何扰动。健康模型的所有信号都应是水平直线：侧向加速度、横摆角速度、侧倾角接近 0，轮荷保持静平衡值，纵向只剩克服滚阻和风阻所需的小量。任何信号出现起伏或漂移，都说明初始化、对称性或数据有问题，例如左右硬点不对称、轮胎文件里的锥度效应（conicity）与角度效应（ply steer）、转向中位偏置。这项检查几乎不花时间，却能在跑大批工况之前拦下大部分低级错误。

动力学初始化：车速、轮速、挡位与转向

静平衡给出了位置，动力学还需要速度。整车以 \(v_0\) 直线行驶时，车身各点的速度都是 \(v_0\)；车轮除了随车身平移还在旋转，其角速度必须与车速匹配：

\[ \omega_0 = \frac{v_0}{r_e},\qquad \kappa = \frac{\omega\, r_e - v_x}{v_x} \](14-5)
  • \(r_e\)：有效滚动半径（effective rolling radius），介于自由半径 \(r_0\) 与静载半径 \(r_l\) 之间，子午线轮胎常用经验近似 \(r_e\approx r_0-\delta/3\)（\(\delta\) 为静态压缩量）；\(\kappa\)：纵向滑移率（第 7 章）
  • 例：自由半径 0.33 m、前轮静压缩 \(4485/220\approx20.4\ \mathrm{mm}\)，则 \(r_l\approx0.310\ \mathrm m\)、\(r_e\approx0.323\ \mathrm m\)，与示例车滚动半径 0.32 m 一致
  • 初始化时若 \(\omega_0 r_e\ne v_0\)，第一步就带着非零滑移率，轮胎立刻产生纵向力

轮速不匹配的后果与程度有关。车轮初始转速为 0 是最极端的情况：起步那一刻四个车轮都是 100% 滑移，相当于抱死拖行，轮胎产生接近附着极限的制动力，直到路面把车轮“拖转”起来。轮速只差几个百分点时，轮荷几乎不受影响，纵向加速度上却会出现一个尖峰。除了轮速，初始化还要关心：

  • 挡位与发动机转速：初始挡位要与初始车速匹配，否则发动机转速越限、离合器打滑，传动系出现冲击；
  • 维持车速所需的驱动力：匀速工况一开始就要克服滚动阻力和风阻（示例车 80 km/h 时风阻 \(\tfrac12\rho C_dA v^2=0.5\times1.2\times0.68\times22.2^2\approx201\ \mathrm N\)），车速控制器的积分项从 0 起步，车速会先略微下降；
  • 转向零位：方向盘初始转角、转向器齿条位置、驾驶员模型的内部状态都应对应直行；
  • 高速时的姿态：空气升力和驱动力会改变高速时的车身姿态。严格的做法是在目标车速下求一次准静态平衡（部分软件提供此选项，以软件文档为准），或留出足够长的稳定段让姿态自然收敛。
易错：初始车速与轮胎转速不一致
只给车身设了 80 km/h 初速度，车轮转速保持默认值 0；或者用自由半径 0.33 m 计算初始轮速，觉得“差 3% 不要紧”。 轮速必须按式 (14-5) 用有效滚动半径初始化。轮速为 0 时，演示 C 中纵向加速度出现约 −0.91 g 的冲击、车头下点约 0.87°，3 s 后车速已掉了约 1.9 km/h；用自由半径算轮速（偏低 3%）时轮荷几乎不变，纵向加速度仍有约 −0.5 g 的尖峰——若指标取 \(a_x\) 峰值，或用 \(a_x\) 阈值触发下一段工况，结果就错了。多数软件的整车工况会按车速自动初始化轮速，但自编模型、联合仿真接口或从中间状态重启时，一定要亲自核对。
易错：把初始瞬态当成车辆响应
工况从 t = 0 就开始施加输入，指标在整段数据上取最大值或平均值。 即使初始化完全正确，车速控制器、驾驶员模型和轮胎松弛也需要一点时间进入稳态。工况应先有一段稳定段（直线匀速，通常 1–3 s），在稳定段末尾确认各信号已经平稳，再开始施加输入；指标只在输入开始之后的规定窗口内提取，零点取输入前一小段的平均值。演示 C 中把稳定段从 0.5 s 加到 2 s，各种错误情形残余的轮荷偏差都降到 0.5% 以下——但稳定段只能“等”初始化错误的后果过去，不能代替正确的初始化：轮荷振荡的那两秒车已开出四十多米，路面障碍、事件触发点的相对位置都会跟着变。

14.4 路面与轮胎接地

轮胎是整车与外界唯一的力接口，而轮胎力的一半“输入”来自路面：路面高度决定轮胎压缩量和垂向力，路面附着决定力的上限，路面的方向和起点决定车辆在哪里、朝哪个方向与路面接触。路面定义错了，前面所有的建模工作都会被这一步抵消。本节讲路面的描述方式、轮胎与路面的接触方法，以及最常见的三类错误：单位、方向起点和初始穿透。

路面的三种描述方式

按几何复杂程度，路面可分为平路、2D 路面和 3D 路面。多体软件一般用路面属性文件描述路面（Adams 的 .rdf，以及 ASAM 维护的 OpenCRG 格式 .crg，见第 3 章），随机路面谱的生成方法见 第 13 章 平顺性与路面。

附着系数、坡道与横坡

附着条件是路面最重要的“非几何”属性。均匀附着用于常规操稳；对开路面（左右轮附着不同）用于检验制动跑偏和 ESC；对接路面（行驶方向上附着突变）用于检验 ABS 与牵引力控制的响应；局部湿滑区可以模拟“单轮踩到水坑”。有两点要特别注意：

  • 路面附着往往是缩放系数，不是绝对值。多数实现中，路面给出的附着系数是对轮胎模型自身摩擦特性的缩放（乘法关系）：轮胎文件本身在额定载荷下峰值摩擦系数为 1.1、路面设为 0.5 时，实际峰值约 0.55，而不是 0.5。具体乘法关系以所用轮胎模型与路面文件的文档为准，使用前最好做一次单轮验证。
  • 附着突变处的轮胎响应需要时间。轮胎力从一种附着过渡到另一种附着要经过松弛长度量级的距离（示例轮胎松弛长度 0.45 m，见第 7 章），对接路面的控制器响应评价必须使用含松弛特性的轮胎模型。

坡道（grade）和横坡（bank）改变的是重力相对车辆的方向：10% 纵坡相当于沿路面方向有 \(g\sin(\arctan0.1)\approx0.10\,g\) 的重力分量，驻坡、坡起和坡道制动工况都依赖它；2% 横坡会给车辆约 0.02 g 的侧向重力分量，直线行驶时需要一点方向盘修正，跑偏试验必须扣除它。不同软件有的通过旋转路面、有的通过旋转重力方向来实现坡道，两者对“车辆坐标系下的加速度信号”含义不同，后处理时要知道当前用的是哪一种（以软件文档为准）。

轮胎与路面怎样接触

轮胎模型首先要回答“轮胎被压缩了多少”。最简单的做法是单点接触：取轮心正下方路面上的一点，用轮心到路面的距离计算压缩量，再由垂向刚度和阻尼得到垂向力：

\[ F_z = k_t\,\delta + c_t\,\dot\delta,\qquad \delta=\max\left(0,\ r_0-h\right) \](14-6)
  • \(k_t\)、\(c_t\)：轮胎垂向刚度与阻尼（示例车 \(k_t=220\ \mathrm{N/mm}\)）；\(r_0\)：自由半径；\(h\)：轮心沿路面法向到路面的距离
  • 静压缩量 \(\delta_s = F_{z0}/k_t\)：前轮 \(4485/220\approx20.4\ \mathrm{mm}\)，后轮 \(3363/220\approx15.3\ \mathrm{mm}\)；\(\max(0,\cdot)\) 表示轮胎离地时垂向力为零，不能“拉住”路面

单点接触在平路和长波路面上足够，但真实轮胎的接地印迹（contact patch）有长度，乘用车大约在 0.15 m 量级。轮胎驶过台阶时，印迹会“包住”台阶，垂向力在一段距离内平滑上升；单点模型却在轮心越过台阶边缘的一瞬间让压缩量突变，于是算出极陡的冲击力。为此发展出了包络（enveloping）接触方法：在印迹范围内用多个点或等效的椭圆凸轮扫描路面，求出一个等效路面高度和等效坡度；耐久和路沿冲击还会用带三维接触和柔性胎体的轮胎模型。轮胎模型的选型见第 7 章表格，本节只强调“路面特征长度决定接触方法”。

易错：用单点接触去“压”短波障碍
操稳模型里的轮胎和接触方法原封不动拿来跑减速带、坑洼、路沿冲击，得到很大的冲击载荷，直接用于强度校核。 路面特征长度与接地印迹长度相当或更短时（台阶、减速带、坑洼、路沿、接缝），单点接触会严重高估冲击力的峰值和上升速率，还会把能量错误地激发到高频。这类工况要换用具有包络功能的轮胎模型或三维接触模型，并核对轮胎模型的适用频带；同时输出频率也要相应提高（14.6 节）。反过来，平路操稳没必要用复杂接触模型，只会多花计算时间。

起点、方向与单位

路面文件有自己的坐标原点和方向，车辆模型也有自己的全局坐标。两者必须在“车辆从哪里出发、朝哪个方向开”这件事上对齐：

  • 方向：Adams/Car 整车模型的全局坐标通常是 X 向后、Y 向右、Z 向上（第 2 章），车辆向前行驶意味着沿全局 −X 方向运动。如果路面障碍沿某个方向排列而车辆朝相反方向出发，车辆会“背对”障碍行驶，根本碰不到它；横坡、对开路面的左右也会跟着颠倒。路面与车辆之间通常通过参考标记（reference marker）或起点 / 朝向参数对齐，具体参数名以软件文档为准。
  • 起点：车辆起点要落在路面定义范围内，而且要在第一个障碍之前留出足够长的稳定段（14.3 节）；路面长度要覆盖整个工况，包括稳定段和工况结束后的余量。车辆驶出路面定义范围时，有的实现报错，有的“掉”到默认平面上继续算——后者更危险，因为它悄无声息。
  • 单位：属性文件一般在文件头的单位段声明长度、角度等单位。高程用 mm 写却声明为 m，路面起伏就被放大 1000 倍；坡度给成百分比却按角度读取，10% 坡变成 10° 坡（约 17.6%）。随机路面谱的功率谱密度单位（第 13 章）更容易出错。
避坑：路面文件的单位、方向和起点
拿到同事的路面文件直接挂上，跑完看轮荷“有起伏”就认为车辆压过了障碍；左侧单边冲击的结果用于左侧零件校核。 每个新路面文件都要做三件事：① 读文件头，确认单位与坐标定义；② 在 t = 0 时把路面与车辆画在同一个三维视图里，确认车辆在路面范围内、车头朝向正确、障碍在前方且位于预期的一侧；③ 先用低速跑一遍，核对轮心垂向位移的起止位置、幅值与障碍尺寸一致（例如 50 mm 台阶对应约 50 mm 的轮心抬升，而不是 0.05 mm 或 50 m）。左右、前后弄反的结果比算不出来更糟糕，因为它看起来“很正常”。

轮胎初始穿透

轮胎初始穿透（initial penetration）是指动力学开始时轮胎压缩量与平衡状态不一致：路面高度在起点处不为零（文件原点偏置、起点落在障碍或坡面上），轮胎模型的自由半径与模型中轮心高度不匹配，或者静平衡是在平路上做的、动力学却在另一块高度不同的路面上开始。它的典型症状是 t = 0 时垂向力尖峰和车身被“弹起”（表 14-5）。

算例 14-4：20 mm 的初始穿透有多大影响

示例车前轮静载 4485 N，轮胎垂向刚度 220 N/mm，静压缩量 20.4 mm。若起点处路面比静平衡时所用路面高 20 mm，动力学开始时轮胎被额外压缩 20 mm，按式 (14-6) 垂向力立刻增加 \(220\times20=4400\ \mathrm N\)，前轮轮荷从 4485 N 跳到约 8885 N，几乎翻倍（演示 C “轮胎初始穿透”情形：前轮最大 8885 N，车身被弹起约 30 mm，约 0.86 s 后才回到 ±2% 以内）。

对比：同样的 20 mm 若是“车身高度”误差（弹簧侧），轮荷变化只有 \(23\times20=460\ \mathrm N\) 左右的量级——轮胎垂向刚度大约是轮心刚度的 10 倍，所以轮胎侧的几何不一致比悬架侧敏感一个数量级。

要点：静平衡最好在工况真正使用的路面和起点上做

静平衡和动力学用同一块路面、同一个起点，轮胎压缩量就天然一致，初始穿透问题自动消失。若工况必须从起伏路面中途开始（例如截取耐久路的一段），宁可从平路驶入、在平路段完成稳定，再进入目标路面，也不要让车辆“凭空”出现在起伏路面上。

14.5 驾驶员模型与事件

真实试验里有一位驾驶员，虚拟试验里也需要一位“虚拟驾驶员”：它决定方向盘怎么转、油门和制动怎么踩。驾驶员可以是一条预先给定的输入曲线（开环），也可以是一个根据车辆状态实时修正的控制器（闭环）。本节讲两类输入的适用场合、预瞄驾驶员的原理和参数整定，以及怎样把一个完整工况组织成“小工况序列 + 结束条件”的事件。最重要的结论是：闭环工况的结果是“车 + 驾驶员”的结果。

开环与闭环：两类输入

开环（open-loop）输入按时间给定，不管车辆怎么响应：方向盘转角的阶跃、斜坡、正弦与扫频，方向盘力矩（例如回正试验中“松手”就是力矩为零），油门、制动踏板或纵向力的时间历程。它的最大优点是可重复：同样的输入作用在不同的车上，响应差异完全来自车辆本身，所以大多数客观评价工况（角阶跃、扫频、中心区）都用开环（第 12 章）。

闭环（closed-loop）输入由控制器根据车辆状态实时计算，分为横向控制（路径跟踪：让车辆沿给定路径行驶）和纵向控制（车速跟踪：保持或按规律改变车速）。凡是由“几何”或“目标状态”而不是由“输入”定义的工况都需要闭环：双移线要求车辆穿过桩桶通道，定半径稳态回转要求车辆保持在圆上，赛道圈速要求沿最优线行驶。

预瞄驾驶员的原理

人开车时眼睛看的不是车头正前方，而是前方一段距离的路。预瞄驾驶员（preview driver model）就模仿这一点：在路径上取一个预瞄点 P，根据 P 在车辆坐标系中的方位决定方向盘转角。课程模型 VMD.veh.PreviewDriver 采用单点预瞄中最经典的纯追踪（pure pursuit）算法，再加上神经肌肉滞后：

\[ L_d=\max\left(L_{min},\ T_p\,v_x\right),\qquad \delta_{cmd}=\left(1+K v_x^2\right)\arctan\frac{2L\sin\eta}{l_P} \](14-7)
\[ \tau\,\dot\delta_{sw}+\delta_{sw}=i_s\,\delta_{cmd} \](14-8)
  • \(T_p\)：预瞄时间（preview time）；\(L_{min}\)：低速时的最小预瞄距离（课程模型 4 m）；\(\eta\)：P 点相对车辆纵轴的方位角；\(l_P\)：车辆到 P 的直线距离
  • \(\kappa_P=2\sin\eta/l_P\) 是纯追踪圆弧的曲率；\(\arctan(L\kappa_P)\) 是低速运动学（阿克曼）转角；因子 \(1+Kv_x^2\) 是驾驶员对不足转向的补偿，课程模型取 \(K=1.4\times10^{-3}\ \mathrm{s^2/m^2}\)，与二自由度模型的稳定性因数一致——相当于驾驶员“熟悉”这辆车
  • \(\tau\)：神经肌肉滞后（neuromuscular lag），把指令变成手臂动作的一阶滞后；\(i_s\)：转向比（示例车 16）

式 (14-7) 的物理意义很直观：P 偏左越多（\(\eta\) 越大）、离得越近（\(l_P\) 越小），需要的转弯曲率越大。预瞄时间 \(T_p\) 实际上是驾驶员的“增益旋钮”：在 70 km/h 时，\(T_p=0.8\ \mathrm s\) 对应 15.6 m 的预瞄距离，\(T_p=0.3\ \mathrm s\) 只有 5.8 m。同样 0.5 m 的横向偏差，在 5.8 m 外看起来的方位角约是 15.6 m 外的 2.7 倍，驾驶员就会打出大得多的方向——这正是预瞄过短时容易振荡的原因。人类驾驶员的预瞄时间常见在 0.5–1.5 s 量级，神经肌肉滞后在 0.1–0.2 s 量级，车速越高、路越熟，预瞄越远（量级参考，因人因工况而异）。

深入：单点预瞄之外的驾驶员模型

单点预瞄只看一个点，对复杂路径（连续弯、变曲率）跟踪精度有限。常见的改进方向有三类：① 多点预瞄，把若干预瞄点的偏差加权；② 最优预瞄控制（optimal preview control，MacAdam 提出），驾驶员用一个内部车辆模型预测未来一段时间的轨迹，使预瞄窗口内的横向偏差加权和最小，郭孔辉提出的预瞄—跟随理论也属于这一思路；③ 模型预测控制（MPC）类驾驶员，在每个时刻求解带约束的有限时域优化问题，可以显式处理附着极限。从人机控制理论看，McRuer 的交叉模型（crossover model）指出：熟练操作者会调整自己的增益和超前 / 滞后，使“人 + 车”开环传递函数在交叉频率附近近似为 \(\omega_c e^{-\tau_e s}/s\)，这解释了为什么人在不同车上都能开得“差不多”——也提醒我们，固定参数的驾驶员模型并不会像人那样自适应。

事件：小工况序列 + 结束条件

易错：结束条件只写时间，或者只写一个带噪声的阈值
稳定段写成“t ≥ 3 s 结束”；或者写成“横摆角速度小于 0.1 °/s 时结束”，没有保持时间，也没有超时保护。 只按时间结束，车速偏低时车辆可能还没到达规定位置就进入下一段，或在工况完成后白跑很久；只按信号阈值结束，噪声可能让条件提前满足，也可能永远满足不了，工况一直跑到最大时长。可靠的写法是“主条件（距离、位置、车速）+ 保持时间（如持续 0.5–1 s）+ 超时保护（超时强制结束并标记失败）”。批处理时要记录每个小工况是因哪个条件结束的，因超时结束的工况结果不能直接使用（14.6 节）。
工程经验：车速控制器也是“驾驶员”的一部分

纵向控制同样会影响横向指标：双移线中车速掉了 3 km/h，侧向加速度峰值就会明显下降。车速 PI 控制器要注意三点：积分饱和要有限幅（anti-windup），否则大偏差之后会长时间超调；积分初值要与匀速行驶所需的驱动力一致，否则工况开始时车速先掉后升（14.3 节）；驱动力上限要符合动力总成能力，不能让一辆 1.6 t 的轿车在仿真里“无限加速”。试验规程对车速控制有明确要求时（例如进入通道后是否松油门），应按规程原文设置。

14.6 求解设置

模型、路面和驾驶员都准备好了，最后由求解器把它们变成一串数字。求解设置决定三件事：算得准不准、算得快不快、能不能算完。本节依次讲积分器的选择、误差容限与最大步长、输出步长与关心频率、仿真时长与效率，以及批量运行时必须做的合理性检查。具体参数名称与默认值随软件和版本变化，以软件文档为准；这里讲的是通用原理和判断方法（多体积分器的基础见 第 1 章）。

积分器：整车模型是“刚性”系统

整车模型里同时存在很慢和很快的运动：横摆、侧倾等操稳模态在 1–2 Hz，车轮跳动约 12 Hz，而一根小质量连杆两端的硬衬套、发动机悬置、轮胎纵向滑移的动态可以快到几百赫兹甚至上千赫兹。最快与最慢时间尺度相差几个数量级的系统称为刚性（stiff）系统。显式积分方法（如四阶龙格—库塔 RK4）的稳定步长受最高频率限制：

\[ h \lesssim \frac{c}{\omega_{max}} \](14-9)
  • \(\omega_{max}\)：模型最高固有圆频率；\(c\)：与方法有关的常数，RK4 在虚轴上的稳定边界约为 2.8
  • 例：0.5 kg 的连杆由 20 kN/mm 的衬套支承，\(\omega=\sqrt{2\times10^{7}/0.5}\approx6300\ \mathrm{rad/s}\)（约 1 kHz），RK4 稳定步长约 0.44 ms；而描述 1 Hz 的操稳响应，10 ms 的步长就足够精确

也就是说，显式方法为了一个“没人关心”的千赫兹衬套模态，不得不把整个仿真的步长压到亚毫秒级。隐式方法（implicit method）没有这个稳定性限制，步长只由精度决定，代价是每一步都要用牛顿迭代求解一组非线性方程（需要雅可比矩阵）。所以通用多体软件在整车仿真中主要使用隐式变步长积分器；课程的 VMD.veh.Vehicle 只有十几个状态、最高频率不高，才可以用 RK4 加 5 ms 定步长。

误差容限与最大步长

变步长积分器每一步都会估计局部截断误差，误差超过容限就缩小步长重算，误差远小于容限就放大步长。误差容限（error tolerance）越小，步长越小，结果越准，计算越慢。容限具体作用在哪些量上、是绝对误差还是相对误差，各软件定义不同，以软件文档为准。判断容限是否合适的办法只有一个——收敛性检查：把容限缩小为原来的 1/10 重跑，关心的指标变化小于 1% 左右（示例阈值），才说明结果已不受容限影响。

最大步长（maximum step size，Adams 中常称 HMAX）是另一道保险。在平稳段，积分器会把步长放得很大；这时如果输入里有一个很短的特征（短时冲击、快速阶跃、短小障碍），大步长可能直接“跨过”它，或者只在它上面落一两个点。最大步长应小于最短输入特征持续时间的 1/5–1/10，同时一般不大于输出步长。

算例 14-5：短小障碍需要多小的步长

示例车以 80 km/h（22.2 m/s）驶过一个沿行驶方向长 0.1 m 的凸块。考虑接地印迹长度约 0.15 m，轮胎与凸块的作用距离约 0.25 m，作用时间只有 \(0.25/22.2\approx11\ \mathrm{ms}\)。若希望在这个力脉冲上至少有 10 个积分点，最大步长应不大于约 1 ms；若沿用操稳工况常见的 5–10 ms 最大步长，积分器在平路段放大步长后可能只在脉冲上落一两个点，算出的峰值力可能偏小，也可能偏大，并且对步长的取法很敏感。

同样的道理适用于输入：0.1 s 内完成的方向盘阶跃，最大步长取 10 ms 时整个上升段只有约 10 个点，基本可以接受；取 50 ms 就只剩两个点，阶跃的形状和响应时间都会失真。

易错：误差容限“越小越好”，或者放宽容限来“解决”不收敛
一种做法是把容限设得极小，觉得这样最准；另一种是模型报不收敛就把容限放宽 100 倍，能算完就交结果。 容限过小会让计算时间成倍增加，还可能因舍入误差和数值雅可比的噪声反而难以收敛；容限过大则会漏掉短时事件，加速度、力这类导出量出现数值噪声。正确做法是：先在基准容限下排查不收敛的模型原因（不连续、初始化、冗余约束），再用“容限缩小 10 倍、最大步长减半”的收敛性检查确认关键指标稳定。把收敛性检查的结果写进报告，比任何一个“推荐值”都可靠。

输出步长与关心频率

输出步长（output step）和积分步长是两回事：积分步长是求解器内部的，可变；输出步长只决定把哪些时刻的结果存下来，通常是固定的。初学者常认为“积分器算得很准，存多少点无所谓”，其实存下来的数据是对连续解的采样，采样定理同样适用：

\[ f_a=\left|\,f-k f_s\,\right|,\qquad k=\operatorname{round}\!\left(f/f_s\right) \](14-10)
\[ \varepsilon_{peak,max}=1-\cos\frac{\pi}{N},\qquad N=\frac{f_s}{f} \](14-11)
  • \(f_s\)：输出频率（输出步长的倒数）；\(f\)：信号中某个频率成分；\(f_a\)：它在采样数据中表现出来的频率。\(f\) 低于奈奎斯特频率 \(f_s/2\) 时 \(f_a=f\)，高于时被“折叠”成低频的假信号，这就是混叠（aliasing）
  • \(N\)：每个周期的采样点数；\(\varepsilon_{peak,max}\)：峰值恰好落在两个采样点正中间时的最坏峰值误差。\(N=5\) 时 19.1%，\(N=10\) 时 4.9%，\(N=20\) 时 1.2%

两个公式给出两条不同的要求：要正确反映频率成分，输出频率至少是最高显著频率的 2 倍（奈奎斯特条件）；要正确读出峰值，每个周期需要 10–20 个点，即输出频率是关心频率的 10–20 倍。还有一点与试验数据采集根本不同：试验的数采系统在采样之前有模拟抗混叠滤波器，而仿真输出是对连续解的“瞬时值”采样，前面没有任何滤波——凡是模型里存在、而输出频率又不够高的成分（车轮跳动、衬套模态、数值噪声），都会原封不动地折叠进低频。所以仿真的输出频率要按“模型里实际存在的显著频率”来定，而不只是按“我关心的频率”来定。要与以较低频率采样的试验数据比较时，正确的做法是仿真以高频输出，再在后处理中复现试验数采链的滤波与降采样。

观察要点：① 默认输出步长 0.05 s（20 Hz）：奈奎斯特频率 10 Hz，12 Hz 的车轮跳动被折叠成 8 Hz 的假振荡；0–10 s 内捕获的峰值只有 1.189，比真实峰值 1.392 低 14.5%；把“采样起点偏移”拖到 50%，峰值又变成 1.368（−1.7%）——峰值读数随采样相位跳动；② 选 1/13 s（13 Hz）：12 Hz 分量混叠成 1 Hz，与真实的 1 Hz 运动叠在一起无法区分，采样数据里“1 Hz 分量”的幅值读成 0.60（真实为 1.00）；选 1/12 s（12 Hz），12 Hz 振动要么完全消失、要么变成常值偏移（拖动采样起点看看）；③ 选 0.01 s（100 Hz）或更小，每个 12 Hz 周期 8 个点以上，默认起点下峰值误差不到 0.1%；④ 下图：截止频率 2 Hz 的一阶滤波让 1 Hz 分量滞后约 68 ms、幅值降到 0.84；同一滤波器正反向各滤一次（零相位）滞后为 0、幅值降到 0.71；在 13 Hz 输出下再怎么滤波，也救不回已被混叠污染的 1 Hz 分量。

为了让结果文件小一点，平顺性或冲击工况也沿用 0.05 s 的输出步长；看到 8 Hz 的振荡，开始分析“8 Hz 共振”来自哪个部件。 仿真输出没有抗混叠滤波，高于奈奎斯特频率的成分会被折叠成假的低频成分，峰值也会因为采样点没落在峰上而偏小。输出频率应按模型中存在的显著频率确定：操稳工况常用 100–200 Hz；含车轮跳动和轮荷峰值的工况至少 200 Hz；冲击、耐久工况要 500–1000 Hz 甚至更高（量级参考）。拿不准时，把输出频率提高一倍重跑，峰值和频谱不变才算可靠。分析“某频率共振”之前，先用式 (14-10) 排除它是混叠产物的可能。

仿真时长与计算效率

仿真时长 = 稳定段 + 工况本身 + 响应收敛的余量。角阶跃要在输入之后留出足够长的稳态段来计算稳态值（第 12 章）；扫频的时长由最低频率和需要的周期数决定；稳态回转的车速斜坡越慢，准稳态越好，时长也越长。时长不够，稳态值取在尚未收敛的区段；时长过长，只是浪费计算资源。

影响计算效率的主要因素，按经验大致排序：模型中的高频成分与不连续性（决定步长和迭代次数）、柔性体模态数与接触对数量、轮胎模型的复杂程度（带包络或三维接触的模型远比单点模型慢）、误差容限与最大步长、输出量的数量与输出频率（I/O 也有成本）。提高效率的常用手段有：去掉对目标工况没有贡献的高频细节（比如操稳工况不需要的极硬衬套可以换成理想运动副，但要确认 K&C 特性不受影响）、静平衡结果复用、按工况裁剪输出请求、批量任务并行。

批处理与参数扫描

整车项目很少只跑一个工况。一个设计方案通常要跑一整套标准工况（稳态、瞬态、频域、闭环、制动、平顺），每个工况还要左右转各一次；参数研究和试验设计（DOE，见 第 15 章）则要对几十到上百个方案重复这一切。这时必须用脚本驱动：脚本生成方案与工况组合，提交计算，收集结果，自动后处理并汇总成表。批处理的价值不只是省人力，更在于每次都以同样的方式运行和处理，结果才具有可比性。

避坑：批量结果不做合理性检查就进汇总表
100 个 DOE 方案跑完，脚本自动提取指标、拟合响应面，发现某个参数的影响“非常显著”，写进结论。 批量运行中总会有少数工况异常：求解器中途失败只留下部分结果，结束条件超时，车辆失稳打转，轮胎离地，参数组合超出轮胎模型的适用范围。异常结果混进汇总表，会制造出“非常显著”的假效应。每个工况都应自动做健康检查：是否正常跑到结束条件、因哪个条件结束、有无求解器警告；车速、侧向加速度、侧倾角、轮荷是否在合理范围内（轮荷不应为负，持续为零说明离地）；左右转结果是否对称。未通过检查的工况要标记出来，单独查看，而不是让脚本静默地纳入统计。

14.7 后处理

求解器给出的是几十到几百个通道的时间历程，评审会上需要的是几个有明确定义的指标和几张能说明问题的图。后处理（post-processing）就是这中间的翻译过程：选对信号，统一坐标与符号，合理滤波，在规定窗口内提取指标，最后写成可追溯的报告。这一步看似“只是处理数据”，却是整车仿真中人为差错最集中的环节。

符号错误是对标中最常见、也最“丢人”的错误。本教程默认 ISO 8855（X 前、Y 左、Z 上），SAE J670 传统约定为 X 前、Y 右、Z 下，Adams/Car 整车模型全局坐标通常为 X 向后、Y 向右、Z 向上（第 2 章）。由于三者的 X 轴或 Z 轴方向不同，同一个物理动作在不同约定下的符号规律如下：

仿真软件的结果请求可能以全局坐标、车身坐标或某个约定的车辆坐标表达，部分请求还会按 SAE 或 ISO 约定换算后输出，以请求的定义和软件文档为准。测点位置同样重要：加速度计很少恰好装在质心上。对平面运动的刚体，测点 P（相对质心坐标 \(x_P\)、\(y_P\)）的侧向加速度为：

\[ a_{y,P}=a_{y,G}+\dot r\,x_P-r^{2}\,y_P \](14-12)

而固定在车身上的加速度计会随车身侧倾，测到的是比力在车身 y 轴上的投影，其中包含重力分量：

\[ a_{y,\mathrm{meas}}=a_y\cos\varphi+g\sin\varphi \](14-13)
  • \(a_y\)：水平面内的侧向加速度；\(\varphi\)：侧倾角（ISO 正向）。左转时 \(a_y>0\)、车身右倾 \(\varphi>0\)，重力分量使车身固定加速度计的读数偏大
算例 14-6：同一个“侧向加速度”可以差 7.6%

课程整车模型 80 km/h、方向盘 40° 稳态：\(a_y=0.417\,g\)，侧倾 1.82°（第 4 章已引用同一组结果）。由式 (14-13)，固定在车身上的加速度计读数为 \(0.417\cos1.82^\circ+\sin1.82^\circ\approx0.417+0.032=0.449\,g\)，比水平面内的侧向加速度大 7.6%。若试验报告的是车身固定读数、仿真输出的是水平面数值，侧倾梯度、不足转向度这些以 \(a_y\) 为横坐标的指标就会系统性偏差，而且这个偏差随侧倾角增大而增大。

测点位置的影响主要出现在瞬态：角阶跃上升段的横摆角加速度可达 1 rad/s² 量级，测点在质心前方 0.5 m 时，由式 (14-12) 附加约 0.5 m/s²（约 0.05 g）；稳态时 \(\dot r=0\)，\(r^2 y_P\) 项只有千分之一 g 量级。另一个自洽性检查是：稳态时 \(a_y\approx v_x r\)，\(22.2\ \mathrm{m/s}\times0.185\ \mathrm{rad/s}\approx4.11\ \mathrm{m/s^2}=0.419\,g\)，与 0.417 g 吻合。

避坑：坐标系与符号没对齐就开始比较
试验数据按 SAE 约定记录，仿真按 ISO 输出，看到两条曲线反号，就在后处理里给试验数据整体乘以 −1 了事；或者用车身固定加速度计的读数直接和仿真的水平面侧向加速度比较。 “整体乘以 −1”只对 Y、Z 相关的量成立，侧倾角在两种约定下同号，乘错了反而引入新错误。正确做法是为每个通道建立一张“通道定义表”：物理量、单位、坐标系、正方向、测点、是否含静态值，按表逐项换算到统一约定（本教程用 ISO 8855），并按式 (14-12)、(14-13) 统一测点和坐标面。换算完成后用一个简单工况验证：左转弯时 \(a_y\)、\(r\)、\(\varphi\) 应同为正，制动时俯仰角为正（点头）。

滤波：去掉噪声，不要去出新问题

试验信号含有传感器噪声、发动机与路面引起的振动，仿真信号也可能含有刚性模型带来的数值噪声（尤其是加速度和力）。滤波（filtering）可以把它们去掉，但任何因果滤波器（只用当前和过去的数据）都会让信号变“慢”。以最常用的一阶低通滤波为例：

\[ H(j\omega)=\frac{1}{1+j\,f/f_c},\qquad \phi(f)=-\arctan\frac{f}{f_c},\qquad \Delta t(f)=\frac{\arctan(f/f_c)}{2\pi f} \](14-14)
  • \(f_c\)：截止频率；\(\phi\)：相位；\(\Delta t\)：等效时间滞后。频率远低于 \(f_c\) 时 \(\Delta t\to1/(2\pi f_c)\)
  • \(n\) 点滑动平均（窗口 \(T_w\)）的时间滞后为 \(T_w/2\)；高阶巴特沃斯滤波器在通带内衰减更平，但相位滞后更大
算例 14-7：一个 2 Hz 低通滤波器能“制造”多少响应时间误差

截止频率 \(f_c=2\ \mathrm{Hz}\) 的一阶低通，在 1 Hz 处相位滞后 \(\arctan0.5=26.6^\circ\)，等效时间滞后 \(26.6/360\ \mathrm s\approx73.8\ \mathrm{ms}\)，幅值衰减到 \(1/\sqrt{1.25}=0.894\)；对更慢的信号，滞后趋近 \(1/(2\pi\times2)\approx79.6\ \mathrm{ms}\)。乘用车横摆角速度的响应时间本身就在 0.1 s 量级（第 11、12 章），如果只对试验数据做了这样的滤波、仿真数据没有做，两者的“响应时间误差”里有七八十毫秒完全是滤波器造成的。演示 E 下图在 20 Hz 输出时算得滞后约 68 ms、幅值 0.84，与连续时间公式的差别来自离散化。

零相位滤波（zero-phase filtering）把同一个滤波器正向、反向各用一次（如 MATLAB 与 SciPy 的 filtfilt），相位滞后抵消为零，幅值衰减变成平方：1 Hz 处为 \(0.894^2=0.80\)。它只能离线使用（要用到“未来”的数据），而且数据两端会有边缘效应，需要预留或延拓。

避坑：滤波引入的相位滞后被当成车辆特性
试验数据噪声大，用 2 Hz 一阶低通滤了一下；仿真曲线很光滑，没有滤波。对标时发现仿真的横摆响应“快了 70 ms”，于是去加大仿真模型的轮胎松弛长度来“修正”。 滤波器本身就会产生几十毫秒的滞后。规则是：仿真与试验数据经过完全相同的处理链（同类型、同阶数、同截止频率、同为因果或同为零相位），或者都用零相位滤波；截止频率远高于所关心的频率；先滤波后求导，但峰值、响应时间等指标优先在未滤波或零相位滤波的数据上提取；标准对滤波有规定时按标准原文执行，并在报告中写明所用的滤波器。

指标提取脚本化

手工在曲线上读数不可重复，也无法批量。指标提取应写成脚本（Python、MATLAB 等），按固定流程执行：

  1. 读入与整理：读取结果文件或导出的数据表，按通道定义表统一单位、坐标与符号；
  2. 对齐与重采样：仿真与试验统一到同一时间基准和采样率（14.8 节）；
  3. 滤波：对所有数据使用同一处理链；
  4. 截取窗口：以输入的 50% 时刻等事件为时间零点，按工况规程截取稳态窗口、拟合区间；
  5. 计算指标：稳态增益（在线性段拟合斜率并注明拟合区间）、响应时间、峰值时间、超调量、1 Hz 相位滞后等，定义见 第 12 章；
  6. 合理性检查与输出：自动标记异常（14.6 节），生成标准格式的图和表。

from scipy.signal import butter, filtfilt

def lowpass_zero_phase(x, fs, fc, order=2):
    """零相位巴特沃斯低通：fs 为采样率，fc 为截止频率（Hz）"""
    b, a = butter(order, fc / (fs / 2))
    return filtfilt(b, a, x)

def step_metrics(t, y, t50, t_ss0, t_ss1):
    """角阶跃指标：t50 为方向盘转角达到 50% 的时刻，[t_ss0, t_ss1] 为稳态窗口"""
    win = (t >= t_ss0) & (t <= t_ss1)
    y_ss = y[win].mean()
    i90 = np.argmax(y >= 0.9 * y_ss)      # 首次达到 90% 稳态值
    ipk = np.argmax(y)
    return {"steady": y_ss, "t_resp": t[i90] - t50,
            "t_peak": t[ipk] - t50, "overshoot": (y[ipk] - y_ss) / y_ss}

14.8 仿真—试验对标

对标（correlation）要回答的问题是：这个模型在什么范围内、以多大的误差代表真车？它不是“把曲线拟合到重合”。一条重合的曲线可能来自正确的模型，也可能来自几个相互抵消的错误参数；后者在换一个工况时就会露馅。本节讲对标的前提、数据对齐、误差指标、灵敏度排序、参数识别流程，以及对标结论的适用边界。验证（validation）的通用要求可参考 ISO 19364（稳态回转）、ISO 19365（正弦停滞）等仿真验证标准，具体条款以标准原文为准。

对标的前提：同一辆车、同一工况、同一处理

仿真和试验曲线放在一起之前，要先确认比较的是“同一件事”：

  • 同一辆车：试验车的质量与配载、轮胎（规格、气压、磨损、温度）、四轮定位、悬架状态与模型一致；试验前后的称重、四轮定位和 K&C 测量是对标的“地基”（14.2、14.3 节）。
  • 同一工况：车速、方向盘输入、路面附着、坡度与风都要对应。最可靠的做法是用实测的方向盘转角和车速作为仿真输入（输入回放），而不是用名义输入——驾驶员实际打出的角阶跃可能只有 38°、上升时间也不是名义值。
  • 同一处理：两边数据经过同样的单位换算、坐标与符号统一、测点修正、滤波和指标算法（14.7 节）。

还要记住，试验数据本身也有误差：传感器标定、安装角度、轮胎温度变化、驾驶员输入的重复性都会带来散布。同一工况通常做多次、左右转各做，用均值和散布范围代表“试验值”；仿真与试验的差异只有明显超出试验散布时才有意义。

数据对齐：时间、零点与坐标

  1. 坐标与符号：按通道定义表把试验数据换算到统一约定（表 14-11）。一个简单的判据：本工况是左转，换算后方向盘转角、横摆角速度、侧向加速度的稳态值应同为正。
  2. 零点：传感器有零点漂移，取输入开始前一小段（如 0.3–0.5 s）的平均值作为零点并扣除；侧倾角、方向盘转角的零点还可能来自安装偏差。
  3. 时间：试验数据的时间零点取决于触发方式，可能比实际输入晚几十毫秒。以输入信号为基准对齐——例如令仿真与试验的方向盘转角都在同一时刻达到 50%——再比较响应。不要用响应信号本身对齐，否则就把要评价的时间误差“对齐”掉了。
  4. 重采样：把两边插值到同一时间网格，注意不要在重采样时引入新的滤波或混叠（14.6 节）。

误差指标

常用的误差指标各自回答不同的问题，应组合使用：

\[ e_G=\frac{y_{ss,sim}-y_{ss,test}}{y_{ss,test}}\times100\% \](14-15)
\[ R^2=1-\frac{\sum_i\left(y_{sim,i}-y_{test,i}\right)^2}{\sum_i\left(y_{test,i}-\bar y_{test}\right)^2} \](14-16)
\[ \mathrm{NRMSE}=\frac{\sqrt{\frac1N\sum_i\left(y_{sim,i}-y_{test,i}\right)^2}}{y_{test,max}-y_{test,min}}\times100\% \](14-17)
\[ \Delta t=\arg\min_{\tau}\sum_i\left[k\,y_{sim}(t_i+\tau)-y_{test}(t_i)\right]^2,\qquad k=\frac{y_{ss,test}}{y_{ss,sim}} \](14-18)
  • \(y_{ss}\)：稳态值（在规定窗口内平均）；\(e_G\)：增益误差，正值表示仿真偏大
  • \(R^2\)：决定系数（coefficient of determination），1 为完全重合，可以为负（仿真比“用试验均值当预测”还差）；NRMSE：以试验数据极差归一化的均方根误差
  • \(\Delta t\)：先用 \(k\) 消除增益差，再用互相关搜索时间平移；本章约定 \(\Delta t>0\) 表示仿真比试验慢

避坑：只调轮胎缩放因子的“万能调参”
对标时发现横摆增益偏大，就把后轮（或前轮）侧偏刚度缩放因子调到曲线重合；稳态对不上调刚度，瞬态对不上调松弛长度，频域对不上再调回来，几轮之后所有曲线都“对上了”。 轮胎缩放因子几乎能影响所有操稳指标，所以它能“吸收”任何来源的误差——K&C、转向柔度、质量惯量、数据处理，甚至符号错误。用它凑出来的模型只在被拟合的那一个工况上成立，换一个车速、换一个侧向加速度水平或换一个信号就会露馅，还会误导后续的设计决策（演示 F 中被“凑”出的后轮侧偏刚度偏大 31%）。正确做法：先对齐数据、核对子系统级数据（K&C、轮胎、质量、转向），再在物理上合理的范围内调整少数有依据的参数；每一项调整都写明理由和幅度，并用没有参与调参的工况验证。

参数识别流程

把上面的思路整理成流程，就是一套系统的参数识别（parameter identification）方法：

  1. 核对数据与对齐：确认车辆状态一致，完成符号、零点、时间、测点的统一；评估试验散布。
  2. 子系统先行：质量与惯量对称重和惯量台（14.2 节），悬架对 K&C 试验（第 9 章），转向对转向台架，轮胎对轮胎试验数据（第 7 章）。子系统对不上，不进入整车对标。
  3. 整车由易到难：先稳态（增益、侧倾梯度、不足转向度），再瞬态（响应时间、超调），最后频域与闭环工况。稳态问题没解决之前，不要调瞬态参数。
  4. 选定待识别参数：依据灵敏度 × 不确定度排序，只选少数几个；为每个参数给出物理上合理的范围（例如衬套刚度 ±20%、轮胎侧偏刚度 ±10%，示例）。
  5. 优化求解：以多信号、多工况的加权误差为目标函数，在参数范围内求最优，见式 (14-20)；参数多时可先做 DOE 与响应面（第 15 章）。
  6. 独立验证：用没有参与识别的工况（不同车速、不同输入、不同信号）检验，误差仍在容差内才算通过。
  7. 记录与归档：每个被调整的参数写明原值、新值、理由与依据，模型版本号随之更新（14.10 节）。
\[ J(\mathbf p)=\sum_{j}\frac{w_j}{N_j\,\sigma_j^{2}}\sum_{i=1}^{N_j}\left[y_{sim,j}(t_i;\mathbf p)-y_{test,j}(t_i)\right]^2,\qquad \mathbf p_{min}\le\mathbf p\le\mathbf p_{max} \](14-20)
  • \(j\)：信号与工况的组合（如角阶跃的横摆角速度、质心侧偏角，稳态回转的侧倾角……）；\(w_j\)：权重；\(\sigma_j\)：该信号的试验散布或允许误差，用来把不同单位的信号放到同一尺度上
  • 只用一个信号构造 \(J\)，就等于允许优化器去找“万能参数”；参数范围约束则防止它跑到物理上不可能的值

对标结论的适用边界

对标完成后，模型获得的是“在验证范围内可信”的资格，而不是“在任何工况下可信”。这个范围应在报告中明确写出，例如：

说明：一个适用范围声明的写法（示例）

“本模型（版本 V2.3）在以下条件下完成验证：车速 60–120 km/h，侧向加速度 0–0.5 g，干燥沥青路面，新胎、标准气压，整备质量 + 驾驶员 + 仪器状态。验证工况为稳态回转、角阶跃与扫频；横摆角速度增益误差不超过 5%，响应时间误差不超过 15 ms，1 Hz 相位误差不超过 5°。超出上述范围（例如极限工况、湿滑路面、满载）的结论仅供趋势参考。”

边界的来源是物理的：线性区对标好的模型，其轮胎在大侧偏角下的饱和、联合滑移和载荷敏感性没有被验证；缓冲块在小侧倾时根本不接触；干路的轮胎数据不能代表湿路；空载状态下的质心高度和惯量不同于满载。越出边界并不一定出错，但出错时没有任何证据能提前告诉你。

避坑：把模型用到验证范围之外
模型在 0.4 g 以内的稳态和角阶跃上对标良好，于是直接用它评估双移线极限车速、正弦停滞工况下的 ESC 介入时机，或者满载、湿路下的稳定性，并把结论写成“满足要求”。 极限工况依赖的是对标时没有检验过的特性：轮胎峰值与饱和、联合滑移、缓冲块与限位块、大轮跳下的 K&C 非线性、控制器逻辑。用线性区对标过的模型做极限评估，至少要补充相应的子系统验证（轮胎极限数据、缓冲块特性、大位移 K&C），或者补一组极限工况的整车对标；做不到时，在报告中把结论降级为“趋势参考”，并说明不确定性的来源。

14.9 联合仿真与扩展

现代汽车的底盘性能越来越多地由电子控制决定：ESC 用单轮制动修正横摆，EPS 决定转向手感，半主动 / 主动悬架改变车身姿态，ADAS 直接替驾驶员转向和制动。多体模型擅长描述“车”，却不擅长描述控制逻辑；控制工具擅长描述逻辑，却没有高保真的车辆。联合仿真（co-simulation）把两者接起来；再往前走，就是实时模型、硬件在环和驾驶员在环。本节介绍这些扩展的基本概念和最容易出错的地方。

为什么要联合仿真

ESC / ABS / TCS

控制器根据横摆角速度、侧向加速度、轮速估算车辆状态，决定各轮制动压力或发动机扭矩。评价正弦停滞、对开路面制动等工况时，控制器逻辑与整车动力学必须一起算。

EPS 与线控转向

助力特性、阻尼与回正补偿决定转向力矩和中心区手感。转向系统的柔度、摩擦和惯量在多体侧，助力算法在控制侧（第 8 章）。

主动悬架与 ADAS

天棚控制等悬架算法需要车身速度和相对速度；车道保持、自适应巡航需要传感器模型与轨迹规划。它们都依赖准确的车辆响应。

工程上常见的组合是：多体软件提供整车“被控对象”（plant），控制器在 Simulink 等工具中搭建，两者按约定的输入输出信号交换数据。多体软件一侧的控制接口工具通常提供两种耦合方式：一种是联合仿真，两边各用自己的求解器，每隔一个通信周期交换一次数据；另一种是把一方的方程交给另一方的求解器统一积分（常称函数求值或模型导出）。名称和配置方式以所用软件的文档为准。

通信周期与零阶保持

联合仿真中，两个求解器只在通信时刻 \(t_k, t_{k+1},\dots\) 交换数据，两次通信之间，对方传来的量保持不变，这就是零阶保持（zero-order hold）。图 14-4 画出了这种时序：

纯延时 \(\tau_d\) 不改变幅值，只引入随频率线性增长的相位滞后：

\[ \varphi_d(f)=-360^\circ\cdot f\cdot\tau_d,\qquad \tau_d\approx\frac{H}{2}\ \sim\ \frac{3H}{2} \](14-21)
  • \(H\)：通信周期；零阶保持贡献约 \(H/2\) 的平均延时，若两边按“先算一方、再算另一方”或并行交换的方式推进，还可能多出一个周期（量级估计，具体取决于交换方案）
算例 14-9：10 ms 通信周期对控制回路意味着什么

取 \(H=10\ \mathrm{ms}\)、\(\tau_d\approx1.5H=15\ \mathrm{ms}\)。对带宽在 2 Hz 量级的横摆稳定控制，附加相位滞后 \(360\times2\times0.015\approx11^\circ\)，通常还能接受；对关心到 10–20 Hz 的转向助力与手感回路（量级参考），附加滞后达到 54°–108°，足以把一个实车上稳定的回路变成仿真里的振荡回路。把通信周期缩短到 1 ms，10 Hz 处的附加滞后降为约 5°。

反过来也不对：若真实 ECU 的控制周期是 10 ms，仿真里用 0.1 ms 通信，就会高估控制器的响应能力。通信周期要与控制器在 ECU 中的实际运行周期相符，或至少在其附近做灵敏度检查。

避坑：联合仿真步长与通信周期不匹配
为了算得快，把通信周期设为 10 ms（甚至等于结果输出步长），控制器却是按 1 ms 采样设计的；仿真里出现实车上不存在的高频振荡，就去调控制器参数把振荡“压”下去。 通信周期引入的零阶保持和交换延迟会在闭环中增加相位滞后（式 14-21），可能让原本稳定的回路振荡甚至发散；按仿真调出来的控制参数拿到实车上会过于保守。正确做法：通信周期与控制器在 ECU 中的实际运行周期一致或更短，并远小于闭环带宽对应的周期；离散控制器的采样时间是通信周期的整数倍；多体侧积分器的最大步长不超过通信周期；上线前做一次“通信周期减半”的收敛检查，关键指标不变才可信。

实时模型、硬件在环与驾驶员在环

控制器开发通常沿着一条由虚到实的链条推进：模型在环（MIL，控制算法以模型形式与车辆模型联合仿真）、软件在环（SIL，用生成的控制代码替代算法模型）、硬件在环（HIL，真实 ECU 通过 I/O 接口与实时运行的车辆模型相连）、驾驶员在环（DIL，真人在驾驶模拟器中驾驶虚拟车辆）。HIL 和 DIL 要求车辆模型满足硬实时：每个计算步（常见 1 ms 量级）都必须在规定时间内算完，不允许偶尔超时。这意味着：

  • 使用定步长、计算量确定的积分方法（多为显式或固定迭代次数的半隐式方法）；
  • 避免迭代次数不确定的求解过程和刚性过强的子模型；
  • 模型复杂度要与硬件算力匹配，通常需要对多体模型做降阶。

DIL 还对模型提出了额外要求：转向力矩、车身运动和声音的延迟要足够小，否则驾驶员会感到“发飘”，主观评价失真。

模型降阶：在速度与保真度之间取舍

把一个上百自由度的多体模型变成实时模型，常用以下几种降阶（model order reduction）手段：

  1. 用 K&C 特性表代替连杆机构：悬架不再显式建模每根连杆和衬套，而是用“轮跳 → 前束 / 外倾 / 轮距变化”“力 → 柔度转向 / 柔度外倾”的查表关系描述，数据来自多体模型或 K&C 试验（第 9 章）。
  2. 模态截断：柔性体只保留关心频带内的模态（第 6 章）。
  3. 线性化：在工作点附近把模型线性化成状态空间形式，用于控制器设计和频域分析。
  4. 等效参数化：二自由度、平面双轨 + 侧倾这类低阶模型，用多体模型或试验辨识出的等效参数（第 2 章已埋下伏笔）。课程的 VMD.veh.Vehicle 就是这样一个模型：12 个状态、5 ms 定步长 RK4，在浏览器里计算 10 s 工况只需几十毫秒。

降阶模型同样需要“对标”，只是对标对象换成了完整的多体模型：在同一组工况（稳态、瞬态、频域、闭环）上比较两者，确认降阶模型在目标频带和工作范围内误差可接受。一个有代表性的例子：课程 Vehicle 默认参数下的不足转向度约 2.8 °/g，而二自由度模型的标称值是 2.23 °/g，两者都来自同一辆示例车——Vehicle 内置的等效 K&C 比二自由度模型的等效侧偏刚度隐含的更强。低阶模型的参数必须由更高层级的模型或试验重新辨识，不能想当然地照搬。

14.10 整车仿真工作流程与质量门

前面九节把整车仿真拆成了一个个环节。真实项目中，这些环节由不同的人、在不同的时间完成，模型还会随着设计变更不断迭代。要保证“交出去的每一个结论都站得住”，就需要把检查固化成流程：在关键节点设置质量门（quality gate），没通过的模型不进入下一步。本节给出一套可以直接套用的质量门、一份合理性检查清单和版本管理的要点。

易错：只改了一个子系统，就不必重走质量门
后悬衬套换了新版本，直接替换文件后跑对比工况，把新旧结果的差异当成“衬套的影响”。 换一个子系统可能同时改变了质量（新衬套支架更重）、静平衡姿态（衬套预载不同）、K&C 特性，甚至引入了新的未匹配通讯器。任何变更之后，至少要重走 G1（装配、质量、静平衡、零输入体检）和受影响的 G2 项目，确认差异确实只来自你想研究的那个变化。把这些检查写成脚本，重走一遍只要几分钟。

合理性检查清单

合理性检查（sanity check）是用最简单的物理关系去“抽查”复杂模型的结果，它不能证明模型正确，却能非常高效地发现错误。下面是整车仿真最常用的几条（数值为课程示例车，仅作量级参考）：

  • 力的平衡：静平衡后四轮轮荷之和等于整车重力 15 696 N；稳态转弯时四轮侧向力之和约等于 \(m\,a_y\)。
  • 运动学自洽：侧向加速度、横摆角速度和侧向速度满足 \(a_y=\dot v_y+v_x\,r\)，稳态时 \(\dot v_y=0\)，即 \(a_y\approx v_x r\)：80 km/h、\(r=0.185\ \mathrm{rad/s}\) 时 \(a_y\approx0.419\,g\)，与模型输出的 0.417 g 吻合（14.7 节）。
  • 零输入与对称：零输入直线行驶时信号平直（14.3 节）；对称车辆左转与右转的指标绝对值一致，差异超过 1%–2% 要查明原因（硬点不对称、轮胎锥度、转向中位）。
  • 量级：示例车侧倾梯度 4.36 °/g，二自由度不足转向度 2.23 °/g（课程整车模型约 2.8 °/g），80 km/h 时横摆固有频率约 1.3 Hz；结果偏离同类车型典型值一倍以上时，先怀疑单位和数据。
  • 趋势：加粗后稳定杆应使不足转向减小、增大车速应使横摆增益先增后减（在特征车速附近达到最大，第 11 章）。趋势与理论相反时，几乎一定有错。

版本管理与可追溯

“一年后，能不能复现报告里的那个数？”这是检验仿真工作规范性的最好问题。要做到这一点，归档包里至少要有：装配与全部子系统、属性文件（含版本号）；事件、驾驶员、路面文件；求解设置；后处理脚本及其版本；原始结果文件；报告本身。同时建立变更记录：每一次模型变更写明改了什么、为什么改、依据是什么、影响了哪些结论。

工程经验：把检查变成自动化脚本

人工检查容易漏项，而且越到项目后期越没有时间做。成熟团队的做法是把质量门里能量化的项目都写成脚本：装配后自动输出质量属性并与目标比较；每个工况自动做零输入段与健康检查；批量运行后自动汇总“异常工况清单”；对标脚本自动生成指标表和对比图。脚本本身做版本管理，结果附在报告里。这样，质量门就从“靠人记得”变成“每次都会执行”。

本章避坑清单

  1. 质量重复计入或遗漏：总数差多少只是症状，要按 BOM 找到是哪个部件重复或遗漏，并先分清偏差落在簧上还是簧下（14.2 节）。
  2. 只核对总质量和轴荷：它们不约束质心高和惯量；用车身质量与质心“吸收”所有偏差，只会把错误藏起来（14.2 节、演示 B）。
  3. 没做静平衡就开始动态仿真：车身从设计姿态落到平衡位置的过程会叠加在工况响应上，示例中前轮轮荷摆动 −20.8%，约 1 s 才衰减（14.3 节、演示 C）。
  4. 初始车速与轮胎转速不一致：轮速必须按有效滚动半径 \(\omega_0=v_0/r_e\) 初始化；轮速为 0 会产生约 −0.9 g 的冲击，用自由半径也会在 \(a_x\) 上留下尖峰（14.3 节）。
  5. 把初始瞬态当成车辆响应：工况前留稳定段，在稳定段末尾确认信号平稳，只在规定窗口内提取指标；稳定段不能代替正确的初始化（14.3 节）。
  6. 路面文件的单位、方向和起点没核对：t = 0 时把路面与车辆画在同一视图里，低速试跑核对障碍位置与幅值；Adams/Car 整车通常沿全局 −X 方向行驶（14.4 节）。
  7. 轮胎初始穿透与单点接触误用：20 mm 穿透可让前轮轮荷几乎翻倍；短波障碍要用包络或三维接触模型（14.4 节）。
  8. 驾驶员参数悄悄改变指标：闭环指标是“车 + 驾驶员”的输出，比较车辆时固定驾驶员参数或按同一准则整定，能用开环的优先用开环（14.5 节、演示 D）。
  9. 结束条件只写时间或带噪声的阈值：用“主条件 + 保持时间 + 超时保护”，并记录每个小工况因何结束（14.5 节）。
  10. 输出步长过大：仿真输出没有抗混叠滤波，高频成分被折叠成假的低频，峰值也会丢失；读峰值需要每周期 10–20 个点（14.6 节、演示 E）。
  11. 放宽误差容限来“解决”不收敛：先查不连续、初始化、冗余约束等模型原因，再用“容限缩小 10 倍、最大步长减半”确认结果收敛（14.6 节）。
  12. 批量结果不做合理性检查：失败、超时、失稳、离地的工况混进汇总表会制造假效应，每个工况都要自动健康检查（14.6、14.10 节）。
  13. 滤波引入的相位滞后被当成车辆特性：2 Hz 一阶低通在 1 Hz 处滞后约 74 ms；仿真与试验必须经过同一处理链，或都用零相位滤波（14.7 节）。
  14. 坐标系、符号与测点没对齐：ISO 与 SAE 之间侧向加速度、横摆角速度反号而侧倾角同号；车身固定加速度计含 \(g\sin\varphi\) 分量，示例中偏大 7.6%（14.7 节）。
  15. 只调轮胎缩放因子的“万能调参”：它能吸收任何来源的误差，要用多信号“指纹”（如质心侧偏角）、子系统数据和独立工况约束参数（14.8 节、演示 F）。
  16. 模型用于验证范围之外：线性区对标的模型不能直接用于极限、湿路、满载评估；报告要写明适用范围，超出范围的结论降级为趋势参考（14.8 节）。
  17. 联合仿真通信周期与控制器不匹配：延时引入 \(360^\circ f\tau_d\) 的附加相位滞后，可能造成仿真里才有的振荡；接口单位、符号与初始状态逐个核对（14.9 节）。
  18. 改了子系统却不重走质量门：任何变更后至少重做装配、质量、静平衡与零输入体检，确认差异只来自想研究的变化（14.10 节）。

本章小结与延伸阅读

本章要点

  • 整车仿真是一条流水线：数据准备 → 装配与质量校核 → 静平衡与初始化 → 路面、驾驶员与事件 → 求解设置 → 后处理 → 对标；结果的质量取决于最弱的一环，而不只是模型本身。
  • 质量校核要逐层进行：总质量与簧上 / 簧下划分、轴荷、质心高、惯量；修正车身质量只能放在最后，用它“吸收”误差会把错误藏起来。
  • 每个动力学工况都以静平衡和一致的初速度（轮速 \(=v_0/r_e\)）为起点，先做零输入体检，再留稳定段；未静平衡、轮速不一致、轮胎初始穿透都有各自的“指纹”。
  • 路面要核对单位、方向与起点；闭环工况的指标是“车 + 驾驶员”的输出，预瞄过短会振荡、过长会切弯，事件的结束条件要有保持时间和超时保护。
  • 整车模型是刚性系统，主要用隐式变步长积分器；误差容限和最大步长要做收敛性检查；仿真输出没有抗混叠滤波，输出频率要按模型中存在的显著频率确定。
  • 后处理先统一通道定义（单位、坐标、符号、测点），仿真与试验经过同一处理链；对标要用多信号、多工况、多指标，警惕轮胎缩放因子式的“万能调参”，并写明模型的适用范围。
  • 联合仿真的通信周期会引入附加相位滞后，要与控制器实际运行周期匹配；实时与在环应用需要降阶模型，降阶模型同样需要对标；把检查固化为质量门和自动化脚本。
