# 第一讲：动态类型与作用域闭包

给有 C++ / Java 背景的同事。90 分钟。
课件：`第1次-值和作用域.pptx`。

语法长得像，行为不像。本讲不要求背完转换表，要求遇到一个值时能判断：它是原始值还是引用，比较时有没有被转换，对象是不是同一份。

## 类型（52 分钟）

### 页 3 · 原始值 vs 引用值（约 8 分钟）

七种原始值：`undefined`、`null`、`boolean`、`number`、`string`、`symbol`、`bigint`。其余值都是对象，数组和函数也是。

```js
let a = 1;
let b = a;
b = 2;            // a 仍是 1

const o = { x: 1 };
const p = o;
p.x = 2;          // o.x 也是 2
```

js或者说动态类型的语音，可以简单理解为，他们的类型其实在描述的是等号右边

C++ 对照：原始值像按值传递；对象标签像指针，不是对象本身的拷贝。Java 对照：基本类型按值，对象变量存的是引用。

### 页 4 · typeof 与 null 的历史坑（约 5 分钟）

| 表达式 | 结果 | 怎么记 |
| --- | --- | --- |
| `typeof null` | `"object"` | 初版引擎的类型标记遗留。`null` 仍是原始值，不是对象 |
| `typeof []` | `"object"` | 数组没有自己的 `typeof` |
| `typeof function(){}` | `"function"` | 函数在这里单独一类，但它仍是对象 |

不用 `typeof` 判断 `null`、数组，或「是不是对象」。`typeof` 只适合区分字符串、数字、函数这种大类。

### 页 5 · 显式转换和隐式转换（约 6 分钟）

语言内部做转换时，走的是同一套运算，不是两套规则。

- **显式**：代码里自己写 `Number()`、`String()`、`Boolean()`、`parseInt(str, 10)`。
- **隐式**：代码没写转换函数，求值时语言调用同一套运算。按走哪一条分组：
  - **ToNumber**：`-` `*` `/` `%` `**`，一元 `+` / `-`，`++` / `--`。`<` `>` `<=` `>=` 在两边不全是字符串时也走它；两边都是字符串则按码元比较，不转数字。位运算 `|` `&` `^` `~` `<<` `>>` `>>>` 先转数字，再收成 32 位整数。
  - **ToString**：`+` 只要有一边是字符串；模板字符串 `` `${x}` ``。
  - **ToBoolean**：`if` / `while` / `for` 的条件、三元 `? :`、`!`。`&&` 和 `||` 用真假决定返回哪一边，返回的仍是原来的值，不是布尔。
  - **`==` / `!=`**：按两边的类型配对转换，不单走上面某一条。`===` / `!==` 不转换。

隐式不是「另一套更宽松的转换」。它只是你没写函数名。

### 页 6 · ToNumber、ToString、ToBoolean（约 8 分钟）

每条只留一个会静默出错的例子。

**ToNumber。** 算术、一元 `+` / `-`、自增自减会走它。大小比较在两边不全是字符串时也走它。位运算走完之后再收成 32 位整数。

- `'5' - 1` 得到 `4`
- `Number("12px")` 得到 `NaN`。整段必须是数字
- `parseInt("12px", 10)` 得到 `12`。这是从前面把数字读走，不是 ToNumber。第二个参数写 `10`

**ToString。** `+` 只要有一边是字符串，两边都变成字符串再拼接。模板字符串 `` `${x}` `` 同样走它。

- `'5' + 1` 得到 `'51'`
- `String(null)` 得到 `"null"`，不是空串

**ToBoolean。** `if` / `while` / `for` 的条件、三元 `? :`、`!` 走它。`&&` 和 `||` 只用它决定返回哪一边。只有六个假值：`0`、`""`、`null`、`undefined`、`NaN`、`false`。

- `if ("0")` 会进。`Boolean([])` 为 `true`
- `ToBoolean("0")` 为真，`ToNumber("0")` 为 `0`。两张表不能混用

守则：要数字用 `Number()`，要解析前缀用 `parseInt(str, 10)`，要真假看那六个假值。不靠运算符暗中转换。

### 页 7 · ==、===、Object.is（约 8 分钟）

| | 先转换吗 | `NaN` | `+0` 与 `-0` |
| --- | --- | --- | --- |
| `===` | 不转 | 不等于自己 | 相等 |
| `==` | 先转换 | 不等于自己 | 相等 |
| `Object.is` | 不转 | 等于自己 | 不相等 |

`==` 的链不能背：

- `0 == ""` 为 `true`
- `"" == false` 为 `true`
- `0 == "0"` 为 `true`
- `"" == "0"` 为 `false`。两边已经是字符串，不再转数字

`Map` / `Set` 用 SameValueZero：`NaN` 等于自身，`+0` 等于 `-0`。和 `Object.is` 差在正负零。

守则：默认 `===`。要判断 `NaN`，用 `Object.is(x, NaN)` 或 `Number.isNaN(x)`。

### 页 8 · NaN、null、undefined（约 7 分钟）

**NaN**

- `typeof NaN === "number"`。它是数字类型里的「不是一个数」
- `NaN !== NaN`。`===` 认不出它
- 用 `Number.isNaN(x)`。全局 `isNaN("abc")` 为 `true`，因为它先做了 ToNumber

**两个空**

- `undefined`：语言留下的空白。未赋值、属性不存在、函数没有 `return`
- `null`：调用方放进去的空。它是原始值，尽管 `typeof` 说它是 `"object"`
- `undefined == null` 为 `true`，`undefined === null` 为 `false`
- 对外接口用 `null` 表示明确的空

### 页 9 · 对象可变、浅拷贝、引用共享（约 8 分钟）

```js
const a = { x: 1, nested: { y: 1 } };
const b = a;
b.x = 2;               // a.x 也是 2

const c = { ...a };
c.x = 9;               // a.x 仍是 2
c.nested.y = 9;        // a.nested.y 也是 9
```

- `b` 和 `a` 是同一个对象。这是引用共享，不是拷贝。
- `{ ...a }` 和 `Object.assign` 只拷一层。嵌套对象仍是同一份。
- `const` 只冻绑定。`a = {}` 会抛，`a.x = 1` 合法。
- `Object.freeze` 也只冻这一层。`seal`、`preventExtensions` 只记名字。

数组同理：`const d = arr` 共享，`[...arr]` 是浅拷贝。

### 页 10 · 函数是值，也是对象（约 4 分钟）

```js
function add(x) { return x + 1; }
const f = add;          // 函数是值，可以赋给变量
f.label = "inc";        // 函数是对象，可以挂属性
function make(n) {
  return () => n;       // 函数也可以当返回值
}
```

函数之所以能 `call` / `apply` / `bind`，是因为它是对象。把函数当参数交出去，是把它这个值交出去。

下一节的闭包就是：这个函数值还记着定义时的绑定。`this` 随调用变化，留到后面，例子是 `setTimeout(obj.method)`。

## 作用域与闭包（27 分钟）

### 页 11 · var 不认花括号（约 4 分钟）

C++ / Java 的 `{}` 产生新绑定。C++ 要写捕获列表，Java 要求捕获的变量不再改。

`var` 不认 `if` / `for` 的花括号，只认函数边界。闭包不写也会记住，记住的是那一个变量，不是一份拷贝。

新代码不用 `var`。这里用它，是因为老代码还在。

### 页 12 · 先写结果（约 4 分钟）

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i));
}
```

先写三行输出，再跑。问的是三次的 `i` 各是多少。`setTimeout` 只说明回调会晚于循环。

### 页 13 · 三个回调共享同一个 i（约 6 分钟）

| 写法 | 输出 | 原因 |
| --- | --- | --- |
| `var` | `3` `3` `3` | 只有一个 `i`。回调跑的时候它已经是 3 |
| `let` | `0` `1` `2` | `for` 每次迭代一个新绑定 |

两种都要现场跑。闭包记住的不是当时的数字，是名叫 `i` 的那个变量。

### 页 14 · 声明可以先看见，赋值不会（约 4 分钟）

| 写法 | 结果 |
| --- | --- |
| `console.log(x); var x = 1;` | `undefined`。声明抬上去，赋值留在原地 |
| `console.log(y); let y = 1;` | `ReferenceError`。声明前是暂时性死区，运行时才报 |

函数声明整段提升今天不单开。

### 页 15 · 闭包记住的是绑定（约 6 分钟）

回到三个 `3`：三个函数值都指着同一个 `i`，不是各抄走一个数字。

- 可以拿来做私有状态。
- 定时器、监听、缓存如果还指着大对象，函数活着，对象就收不走。
- 每次迭代各留一份：用 `let`，或 `function make(i) { return () => console.log(i); }`。工厂函数只给形状。

### 页 16 · 声明怎么写（约 3 分钟）

默认 `const`，要重新赋值用 `let`，不用 `var`。

`const` 不冻对象内容，上一页引用共享已经见过。`arguments` 是类数组，箭头函数没有它。新代码用 `...args`。

## 收束（6 分钟）

**页 17。** 两个人各复述一句：

1. 原始值赋值是另一份，对象赋值是同一份引用。比较默认用 `===`。
2. 函数是值。闭包记住的是绑定，所以 `var` 循环是三个 `3`。

**页 18。** 今天的口袋清单，不是全课速查。

- 七种原始值按值复制。对象、数组、函数按引用共享。
- `typeof null` 是历史坑。`null` 仍是原始值。
- 显式用 `Number` / `String` / `Boolean`。隐式走的是 `ToNumber`、`ToString`、`ToBoolean`。
- 默认 `===`。`NaN` 用 `Object.is` 或 `Number.isNaN`。
- `undefined` 是语言留下的，对外的空用 `null`。
- 展开是浅拷贝。`const` 只冻绑定。
- 函数可以赋值、挂属性、被返回。闭包带走的是绑定。
