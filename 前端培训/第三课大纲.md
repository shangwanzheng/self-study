# 第三课：JavaScript——当你的直觉开始骗你

给有 C++/Java 背景的同事。前两课已经建立页面和工程概念。本课只处理一件事：语法长得像，行为不像。不要求记住全部怪异行为，要求遇到不确定时知道往哪个机制上查。

## 四个主要反直觉特性

| 选择 | 学员要记住的一句 | 
| --- | --- | --- |
| 动态类型 | 变量是标签，不是盒子。类型错配通常不抛，算出一个还能往下用的值 | 
| 函数 | 作用域认函数边界；函数本身是对象，可以单独交出去。闭包记住的是绑定。|
| 原型继承 | 属性运行时沿 `[[Prototype]]` 找。`class` 仍是这套机制，链可以在运行时改 
| 单线程事件循环 | 没有线程、锁、join。异步是排队。外层 `try/catch` 抓不住回调里的抛出

## 模块三：this——看这次怎么调用

函数是对象，可以当参数单独交出去。交出去之后点号没了，接收者就丢了。Java 的方法引用不会丢掉接收者。C++/Java 里实例方法的 `this` 写死在对象上；JS 的 `this` 由这一次调用决定。

课堂上反复问，不必背优先级条文：

1. 前面有点号吗？有，`this` 通常是点号前面的对象。
2. 没有。是箭头函数吗？是，用定义处外层的 `this`。
3. 都不是。是 `new`，或 `bind` / `call` / `apply` 吗？用新实例，或被绑住的那个。
4. 都没有。严格模式是 `undefined`。

例子只留一个：`setTimeout(obj.method, 100)`。修法是箭头函数包一层，或事先 `bind`。不要再写第四种写法。

箭头函数写回调，通常能绕开绑定问题。不要用箭头函数定义对象方法，那时 `this` 不会指向该对象。

## 模块四：原型——运行时往上找

Java 的继承在编译期定好，运行时不能改。JS 先找对象自己的属性，没有就沿内部原型往上，直到 `null`。

本讲只留三句：

- 沿链找。空对象不空，链的底是 `Object.prototype`，上面有 `toString`、`hasOwnProperty`。不要拿 `{}` 当哈希表，字典用 `Map`。
- 别漏 `new`。旧构造函数在非严格模式下漏写 `new`，`this` 会绑到全局对象，而且不报错。`class` 不用 `new` 会直接抛。两句不要并成一句。
- `class` 仍是原型糖，运行时可以改原型，`instanceof` 走原型链。`#private`、`static` 块、`new.target` 只点名。

## 模块五：事件循环——排队，不是并行

C++/Java 可以让多个任务同时在多条线程上跑，用锁、join 或 Future 等结果。JS 主线程一次只做一步：同步代码先跑完，然后清空微任务，再取一条宏任务，接着再清空微任务。

现场预测，先写再跑：

```js
console.log("1");
setTimeout(() => console.log("2"), 0);
Promise.resolve().then(() => console.log("3"));
console.log("4");
```

输出 `1 4 3 2`。同步打印 `1` 和 `4`，微任务打印 `3`，宏任务打印 `2`。`Promise.then`、`queueMicrotask`、`await` 之后的代码是微任务。`setTimeout`、DOM 事件、I/O 回调是宏任务。

工程上三句：

- 忘了写 `await`，拿到的是 Promise，不是值。
- `forEach` 不等待异步回调。要按顺序等待，用 `for...of`。
- `Promise.all` 一个失败就整体失败。要每个结果都留下来，用 `Promise.allSettled`。

错误处理：

- 只有一种运行时异常。没有 checked exception，也没有 `noexcept`，编译期不会帮你查。
- `throw` 可以抛字符串、数字、普通对象。工程上始终抛 `Error`，否则没有堆栈。`cause` 和 `AggregateError` 只点名。
- `try/catch` 只抓同步代码。`setTimeout` 里的 `throw` 进不了外层 `catch`。Promise 的错误用 `.catch`，或 `await` 再包一层 `try/catch`。

**守则**：同步错误用 `try/catch`，Promise 错误用 `.catch` 或 `await` 加 `try/catch`。不要在 JS 里找线程安全；先问这段代码在事件循环的哪一步执行。

## 收束

- `this` 看调用点，箭头函数看定义处的外层。
- 属性沿原型找，字典用 `Map`。
- 异步是排队，`try/catch` 抓不住回调。

## 开场

下面这些规则多数能从第 1 次的类型转换里找到根。单独留一场，是因为业务里每周都会撞上，不能留到事后再查。

## 模块六：数字、数组与遍历

- 日常只有 `Number`，IEEE 754 双精度。超过 `2^53 - 1` 的整数用 `BigInt`，而且不能和 `Number` 混算。`0.1 + 0.2 !== 0.3`。钱用整数分，或单独的 decimal 库，不用 `Number` 做精确相等。
- `[1, 2, 10].sort()` 得到 `[1, 10, 2]`。默认按字符串排序。数值序必须写 `(a, b) => a - b`。
- `sort`、`reverse`、`splice`、`push` 改原数组。业务代码优先用 `toSorted`、`toReversed`、`toSpliced`。
- `for...in` 走可枚举属性名，包括原型链上的，不要用它遍历数组。`for...of` 走值，适用于数组、字符串、`Map`、`Set`。普通对象用 `Object.keys` / `Object.values` / `Object.entries`。
- 一句：`Array(3)` 是三个空槽，不是三个 `undefined`，`map` 会跳过空槽。要三个 `undefined` 用 `Array.from({ length: 3 })`。

## 模块七：JSON、解构与空值

`JSON.stringify` 不是 JS 对象的完整镜像：

- 留下：普通数据、`null`。
- 丢掉：对象里的 `undefined`、函数、`Symbol`。数组里的 `undefined` 会变成 `null`。两种「没有」到了 JSON 里不是同一种结果。
- 变形：`NaN` 和 `Infinity` 变成 `null`，`Date` 变成字符串。
- 抛错：`BigInt`、循环引用。
- 长 id 在契约里用字符串。不要用 JSON 数字对接 Java 的 `Long`。
- 自定义序列化用 `toJSON`，自定义反序列化用 `JSON.parse` 的 reviver。原型污染只说明风险，不演示。

解构和空值是日常写法，和 JSON 放在同一段：

- 解构 `null` / `undefined` 直接抛 `TypeError`。
- 默认值只在值为 `undefined` 时生效。`const { a = 1 } = { a: null }` 得到 `null`。
- 展开是浅拷贝，嵌套对象仍是共享引用。
- `?.` 只停在写了问号的那一层。`obj?.a.b` 在 `a` 为 `null` 时仍会抛。要逐级写成 `obj?.a?.b`。
- `??` 只在 `null` 和 `undefined` 时取右边。`||` 还会把 `0`、`""`、`false` 换掉。`0 ?? 1` 是 `0`，`0 || 1` 是 `1`。

## 模块八：模块、日期与正则

代码怎么进来，各记一句：

- C++ 的 `#include` 在预处理拉文本。Java 的 `import` 在编译期解析类型。
- CommonJS 的 `require` 在运行时同步加载，结果有缓存。`module.exports` 和 `exports` 起初指向同一对象，把 `exports` 重新赋值为另一个对象会断开。
- ESM 的 `import` 静态提升。`export let` 是活绑定，导出方一改，导入方看得到。顶层 `this` 是 `undefined`。动态 `import()` 返回 Promise。
- `package.json` 的 `"type": "module"` 决定 `.js` 按哪套解析。新项目用 ESM。看到 `require` 和 `module.exports` 就知道是 CJS。不要混用。

另外两个静默状态：

- `2024-01-01` 按 UTC 解析，`2024/01/01` 常按本地解析，而且引擎不完全一致。月份从 0 起。`Date` 对象可变，`setDate` 改的是原对象。日期用 ISO 字符串，并写明时区。
- 带 `g` 的正则记住 `lastIndex`。同一个实例第二次 `test` 可能变成 `false`。每次新建，或用完把 `lastIndex` 设回 `0`。

## 收束

- 数字没有整型，`sort` 要传比较函数，JSON 会丢字段。
- 日期用 ISO 字符串加时区，带 `g` 的正则不复用实例。

## 结尾：一页速查

速查不新开话题，每条对应前面三次的内容：

- 默认 `===`，不写 `==`。
- 默认 `const`，需要重新赋值用 `let`，不写 `var`。
- `const` 只冻结绑定。`Object.freeze` 是浅冻结。
- `this` 看调用点。箭头函数看定义处的外层。
- 属性沿原型找。字典用 `Map`。
- 异步先问微任务还是宏任务。`try/catch` 抓不住异步回调里的异常。
- 数字 `sort` 必须传比较函数。
- 超过安全整数用 `BigInt`。钱不用 `Number` 做精确相等。
- JSON 会丢掉 `undefined`、函数、`Symbol`。`NaN` 会变成 `null`。
- 数组用 `for...of`，对象用 `Object.entries`。
- `??` 和 `||` 不是一回事。可选链要逐级写。
- 日期用 ISO 字符串加明确时区。带 `g` 的正则不要复用同一个实例做多次 `test`。

课后练习：给一段同时包含 `var` 循环闭包、丢失 `this` 的回调、`==` 比较、数字 `sort`、JSON 序列化丢字段的代码，让他们标出会静默出错的位置。对答案不占这 15 分钟。
