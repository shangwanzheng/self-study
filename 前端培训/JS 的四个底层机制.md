# 坑从哪来——JS 的四个底层机制

## 一、语言核心机制

- **动态类型 + 鸭子类型**：变量无类型、值有类型；对象只要“有这个方法”就能使用，无需实现某个接口。编译期类型检查不存在，是“静默错配”的总根源。
- **原型继承**：对象沿 `[[Prototype]]` 链在运行时查找属性，原型可随时增删改。ES6 `class` 只是语法糖，底层仍是原型。
- **函数即对象**：函数是 `Function` 的实例，可以挂属性（`fn.cache = {}`），可作为参数和返回值，可动态创建（`new Function`），自带 `call/apply/bind`。
- **闭包隐式捕获整个词法环境**：无需声明捕获列表（对比 C++ 显式捕获、Java 要求 effectively final）。灵活，但容易无意中持有大对象导致内存泄漏。
- **真值/假值隐式转换**：`"0"`、`[]` 为真，`0`、`""` 为假。规则复杂且不可传递，是条件判断误判的高发区。
- **全局对象**：浏览器中是 `window`，Node 中是 `globalThis`；未声明变量赋值、全局函数都挂在其上，可动态增删。

## 二、函数与调用

- **箭头函数的词法 `this`**：没有自己的 `this`，捕获定义时外层的 `this`，对 Java/C++ 同事是全新心智模型。
- **默认参数 + 剩余参数 + 解构参数**：`function f(a = 1, ...rest)`、`function f({ x, y })`。C++ 有默认参数但无解构参数，Java 三者均无（仅 varargs）。
- **IIFE（立即调用函数表达式）**：`(function(){ ... })()`。历史上用于创建私有作用域，现被模块和块级作用域取代，但读老代码必须认识。
- **函数声明提升**：`foo(); function foo(){}` 可正常运行。
- **一等函数**：语法与 C++ `std::function`、Java lambda 相似，但没有函数类型约束，调用时才检查参数，语义更宽松。

## 三、对象与数据

- **解构赋值**：`const { a, b = 2 } = obj`、`const [x, y] = arr`。C++17 结构化绑定语法和范围不同，Java 无。
- **展开运算符**：`{ ...obj }`、`[...arr]`、`f(...args)`。对象/数组字面量展开是 JS 独有，注意是**浅拷贝**。
- **可选链 `?.` 与空值合并 `??`**：`obj?.a?.b` 为语法级短路；`x ?? y` 仅对 `null/undefined` 回退。
- **计算属性名与对象字面量简写**：`{ [key]: value }`、`{ x, y }`、`{ method() {} }`。
- **Symbol**：唯一的原始值，用作属性键避免冲突；`Symbol.iterator` 等是协议钩子。
- **Proxy 与 Reflect**：可拦截对象的基本操作（get/set/has/deleteProperty/apply/construct 等）。Java 动态代理仅针对接口。
- **WeakMap / WeakSet**：键必须是对象且为弱引用，不阻止 GC。用于“给对象挂私有数据而不阻止回收”。不可枚举、无 `size`。
- **BigInt**：`123n` 为语言内建任意精度整数。注意不能与 `Number` 混算。
- **动态增删属性**：`obj.newProp = 1; delete obj.oldProp`。C++/Java 对象结构编译期固定。
- **结构化克隆**：`structuredClone(obj)` 深拷贝，支持 Map、Set、Date、ArrayBuffer 等，不支持函数和原型链。

## 四、异步与并发

- **事件循环 + 单线程异步**：语言层面没有线程、锁、join 概念，所有异步都是“排队执行”。对比 C++ `std::thread`、Java `Thread/Executor/虚拟线程`，并发模型根本不同。
- **Promise 与 async/await 深度整合**：`async` 返回 Promise，`await` 暂停并把后续代码放入微任务队列。语法级且与事件循环强绑定。
- **生成器 `function*` / `yield`**：可暂停恢复的函数，天然实现迭代器协议。Java 无生成器语法。
- **顶层 await**：ESM 模块顶层可直接 `await`，加载会等待其完成。
- **动态 `import()`**：运行时按需加载，返回 Promise。区别于编译期/加载期的 `#include`、`import`。

## 五、语法与表达式

- **模板字符串与标签模板**：`` `Hello ${name}` ``；`` tag`...` `` 可用函数处理静态与动态部分。
- **逗号运算符**：`(a, b)` 求值 a 再求值 b 并返回 b，常见于 `for` 循环和压缩代码。
- **标签语句**：`label: for (...) { break label; }`，介于 C++ `goto` 与 Java labeled break 之间，差异不大。

## 六、模块与元编程

- **ESM 的 live binding**：`export let count` 被修改后，导入方看到的值同步变化。C++ `extern`、Java `static` 字段无此语义。
- **eval 与 new Function**：运行时执行字符串代码。安全风险高，现代代码基本禁用，但读老代码和面试会遇到。
- **标签模板作为 DSL 入口**：如 `styled.div`...``、`` gql`...` ``、`` sql`...` ``，库可据此解析模板内容。

## 七、培训取舍建议

| 优先级 | 特性 | 理由 |
|---|---|---|
| 必讲 | 动态类型、原型继承、函数即对象、闭包隐式捕获、真值转换 | 所有“静默错误”的根源 |
| 必讲 | 箭头函数词法 `this`、解构、展开、可选链/`??` | 日常高频，与旧语言直觉冲突最大 |
| 必讲 | 事件循环、Promise/async-await、微任务/宏任务 | 并发模型完全不同，不建立心智模型无法写异步代码 |
| 选讲 | Symbol、Proxy/Reflect、WeakMap、BigInt、生成器 | 特定场景使用，遇到再查 |
| 选讲 | 标签模板、eval、顶层 await、动态 `import()` | 读老代码或特定框架时需要 |
| 略过 | 逗号运算符、标签语句、IIFE | 知道存在即可 |

---

> **一句话总结**：对 C++/Java 同事来说，JS 真正“新”的不是语法，而是 **动态类型 + 原型继承 + 函数即对象 + 事件循环** 这四个底层机制。其余特性大多是这四个机制的衍生语法，理解了根，枝叶可以现查。
