## 一、单选

每题只有一个正确答案。

**1.** 主仓 `ps-cae-cloud-space-frontend` 怎么跑起来？

- A. 进任意子目录，执行 `pnpm dev`
- B. 在有 `package.json` 的仓库根目录 `npm install`，再 `npm start`，浏览器开 `http://localhost:8000`
- C. 双击 `index.html`
- D. 在根目录执行 `mvn spring-boot:run`

**2.** 地址栏已经是 `/workbench`，要找到该改的页面文件，标准路径的前两步是？

- A. 先改 `craco.config.js`，再看 `dist/`
- B. 用地址对上 `routeConfig`，再打开 `src/pages/` 里的入口组件
- C. 全局搜所有 `.less`
- D. 先在 Network 里清空缓存

**3.** 看到页面旁的 `.less`，和 `import styles from './index.less'` 这种 CSS Modules，课堂怎么区分？

- A. 两者都是预处理器，和 Sass 一类
- B. Less 管 CSS 怎么写；CSS Modules 管类名只在当前组件生效
- C. CSS Modules 是另一种 Less，编译后仍会全局互相覆盖
- D. 本仓不用 Less，样式都写在 JS 里

**4.** Network 里一条请求的 HTTP 状态是 200，页面仍提示失败。先看什么？

- A. 响应 JSON 里的 `code` 是不是 `200`
- B. 一定是 CORS，先改页面
- C. 一定是浏览器还在用旧包
- D. 先把组件重写一遍

**5.** 下面这段在控制台的输出顺序是？

```js
console.log('A')
setTimeout(() => console.log('B'), 0)
Promise.resolve().then(() => console.log('C'))
console.log('D')
```

- A. A B C D
- B. A D B C
- C. A D C B
- D. A C D B

**6.** 写成 `const res = request.get('/api/projects')`，没有 `await`。接着读 `res.data`，最可能是？

- A. `res` 已经是响应体，`res.data` 就是列表
- B. `res` 是 Promise，`res.data` 是 `undefined`
- C. TypeScript 会在运行时拦住这行
- D. 外层 `try/catch` 一定能抓到这个请求后来的失败

**7.** 页面卡住、按钮点了没反应。课堂的判断是？

- A. 地址栏所在的浏览器进程正在算布局
- B. 再开一条 Tomcat 线程去处理响应即可
- C. 这份文档所在渲染进程的主线程被同步代码占住，点击要等它跑完
- D. 主线程和 GPU 进程是同一个东西

**8.** 主仓和 basic 的打包、启动，课堂怎么区分？

- A. 两个仓库都在根目录 `npm start`，打包都是 Webpack
- B. 主仓是 Webpack（经 CRACO），在根目录 `npm start`；basic 是 Vite，要进子目录 `npm run dev`
- C. 两个仓库都是 Vite，命令都是 `pnpm dev`
- D. basic 用 Maven 打包，主仓用 `javac`

**9.** `setTimeout(obj.hi, 0)` 之后，`this` 怎么了？课堂上的修法是？

- A. `this` 仍是 `obj`，不用改
- B. 调用时前面没有点号，`this` 丢了。用箭头函数包一层，或事先 `bind`
- C. 只有 `class` 里会丢，普通对象不会
- D. 换成 `var` 声明就能修好

**10.** 刷新页面之后，正在填的表单没了，语言选择还在。原因是？

- A. 两者都写在 `localStorage` 里
- B. 变量和组件状态没了；语言在 `localStorage`，刷新还在
- C. 两者都没了，语言是下一次接口带回的
- D. 表单在 Cookie 里，语言在内存里

**11.** 按钮点了，只改了本地变量或就地 `push`，界面没有动。缺的是什么？

- A. 再执行一次 `npm install`
- B. 去改同名 `.less`
- C. 调用 `useState` 的更新函数，用新值或新数组替换
- D. 给列表的 `key` 改成数组下标

**12.** React 列表里每一项的 `key`，课堂要求用什么？

- A. 会变的数组下标
- B. 稳定的 `item.id`，不要用下标凑合
- C. 展示给用户的那一列文案
- D. 随机数，保证每次都不一样

**13.** TypeScript 里的 `interface`，打包进浏览器之后还在吗？

- A. 还在，可以用 `instanceof` 判断
- B. 没有了。`as` 只让编译器闭嘴，不检查运行时的对象
- C. 还在，但只对 `class` 生效
- D. 浏览器直接执行 `.ts`，所以类型还在

**14.** 下面这段，`catch` 接不接得住？

```js
try {
  setTimeout(() => { throw new Error('late') }, 0)
} catch (e) {}
```

- A. 接得住，`e` 就是 `late`
- B. 接不住。`try/catch` 只包当前这段同步代码
- C. 只有漏写 `await` 时才接不住，定时器可以
- D. 进程会退出，后面的点击也不能用

**15.** 地址栏从 `/workbench` 改到 `/flow`，Java 那一侧通常怎样？

- A. 一定会再进一次 Controller，因为 URL 变了
- B. 浏览器整页刷新，重新要 `index.html`
- C. 前端换组件，不一定向 Java 发请求。F5 才重新要 `index.html`
- D. 一定先发一条 CORS 预检

**16.** 下面两行的结果分别是？

```js
'5' + 1
'5' - 1
```

- A. 都是数字 `6`
- B. `'51'` 和 `4`。加号碰到字符串会拼接，减号会把字符串转成数字
- C. 都是字符串 `'51'`
- D. 两行都抛类型错误

**17.** `count` 的值是 `0`。`count || 10` 和 `count ?? 10` 分别得到什么？

- A. `0` 和 `0`
- B. `10` 和 `0`。`||` 把 `0` 当成假换成默认值；`??` 只在 `null` 或 `undefined` 时才换
- C. `10` 和 `10`
- D. `0` 和 `10`

**18.** 下面这段能跑完吗？`obj.n` 最后是多少？

```js
const obj = { n: 1 }
obj.n = 2
```

- A. 报错。`const` 和 C++ 的 const、Java 的 final 一样，对象里面也不能改
- B. 能跑完，`obj.n` 是 `2`。`const` 只锁住这个名字不能再指向别处
- C. 能跑完，但 `obj.n` 仍是 `1`
- D. `obj` 变成 `undefined`

**19.** `const p = new Person("ana")` 之后，哪个说法对？

- A. `p.prototype` 就是 `Person.prototype`
- B. `p.prototype` 是 `undefined`。实例上没有 `.prototype`，这条链用 `Object.getPrototypeOf(p)` 看
- C. `p.prototype` 是 `Person` 这个函数
- D. `Object.getPrototypeOf(p)` 一定是 `null`

**20.** `user` 是 `undefined`。`user?.profile?.name` 的结果是？

- A. 抛 `TypeError`，和空指针一样
- B. `undefined`。中间任何一截为空就停住，不再往下取
- C. `null`
- D. 空字符串 `''`

## 二、判断

对的打 √，错的打 ×。

**21.** basic 仓库和主仓一样，在仓库根目录执行 `npm start`。

**22.** `npm run start:mock` 跑的是同一套页面，接口走 Mock，不连真后端。

**23.** `Promise.all` 里只要有一个 reject，整体就 reject。

**24.** `if ({})` 和 `if ([])` 都为真；`if (0)` 和 `if ('')` 都为假。

**25.** `as Project` 会在运行时检查这个对象有没有这些字段。

**26.** hox 里的数据和 Spring 单例一样，刷新页面之后还在。

**27.** `const fn = obj.hi` 之后再调用 `fn()`，`this` 仍然是 `obj`。

**28.** 改了 `craco.config.js` 里的代理地址，不用重启，热更新会带上新地址。

**29.** `for (var i = 0; i < 3; i++)` 里放三个 `setTimeout`，输出是 `0`、`1`、`2`。

**30.** 对象字面量里用箭头函数写方法，`this` 会指向这个对象。
