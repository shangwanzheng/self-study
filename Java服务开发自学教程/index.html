Java 服务开发

按《Java服务开发技能模型》的建议路径来学：先把已有的 HTTP、JSON 和包管理翻译成 Java，再写一个能调试的 Boot 接口，最后看缓存、消息和部署上会错在哪里。全课只用同一笔教学订单。

怎样使用交互演示

  • 分步：点按钮或滑块，读数会跟着变。
  • 曲线：鼠标悬停显示数值，点击图例可以隐藏或显示某条曲线。
