## 基准算例

名称：教学订单。只许引用 `Course.data.order` 和 `Course.orderMath`，不许改数，不许另造同名参数。

- userId = 10001（Long）。JSON 给前端写字符串 `"10001"`。它在 2^53 以内，不能用来演示精度丢失。
- snowflakeText = `9007199254740993`。若以 JSON number 解析，得到 snowflakeRoundedText = `9007199254740992`，差 1。models.js 里两者都是字符串，禁止写成 JS 数字字面量。
- amountYuan = 199.5，amountFen = 19950。199.5 在二进制里可表示，单次转换看不出 double 的错；金额仍用整数分做运算。
- stock = 8
- page = 1，size = 20
- poolCore = 4，poolMax = 8，queueCapacity = 100
- connectTimeoutMs = 500，readTimeoutMs = 2000，browserTimeoutMs = 3000
- listN = 10000
- hashCap = 16，loadFactor = 0.75
- qpsTeach = 50（数量级，不是压测结论）
- heapXmsMb = 256，heapXmxMb = 512（教学用，不是生产配置）
- jdk = 17

由 `Course.orderMath` 算出，不要手写另一套：

- hashThreshold = 12。容量 16、负载因子 0.75 时，插入第 13 个键才扩容。
- rejectTaskNo = 109。假设任务来得及在池还忙时涌入：先占满 4 个核心线程，再放进 100 个队列，再涨到最大 8 个线程，第 109 个走拒绝策略。
