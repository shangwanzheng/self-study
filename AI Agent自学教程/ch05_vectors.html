第 5 章 · 对象与结构

向量与句向量

先分清向量、词向量、句向量，再用余弦看四条规章里哪一条离问句最近。问句整句是一个 4 维向量，最近的是第 3 条。

预计学习 90 分钟 前置：第 1 章至第 4 章 交互演示 2 个
  • 能说明本课向量是长度为 4 的一串数，embedDim 是 4；
  • 能分开词向量和句向量：问句「报销上限是多少」整句对应 \([3,1,0,0]\)，单字「报」没有这个向量；
  • 能按余弦公式写出四条读数：第 3 条为 1，第 1 条为 \(1/\sqrt{10}\)，第 2 条为 \(3/\sqrt{20}\)，第 4 条为 0，并指出最近的是第 3 条；
  • 能说明余弦无量纲、余弦 1 与余弦 0 各表示什么，以及索引和查询必须共用这一套 4 维句向量。

这一章：问句和四条规章怎么比近

档案助理要在四条规章里找出和问句最接近的一条。前面的循环负责决定去查；这一章负责比较本身。顺序是：先分清向量、词向量、句向量，再用余弦看哪一条离问句最近。

问句是「报销上限是多少」，整句收成 \(\mathbf q=[3,1,0,0]\)。四条名称依次是考勤、请假、报销、差旅，向量依次是 \([0,1,0,0]\)、\([1,0,1,0]\)、\([3,1,0,0]\)、\([0,0,1,1]\)。余弦读 Course.agentMath.scores()：第 3 条为 1，第 1 条为 \(1/\sqrt{10}\)，第 2 条为 \(3/\sqrt{20}\)，第 4 条为 0。最近的是第 3 条「报销」。这些读数成立，是因为索引和查询用的是同一套 4 维句向量。把规章写进库、再按片取回，留给第 6 章。

三种向量

5.1–5.3。一串数、一个字的向量、整句的一个 4 维向量。

余弦读数

5.4–5.7。无量纲的余弦。四条走完，第 3 条最近，第 4 条的 0 是不相关。

同一套坐标

5.8。索引用的向量和查询用的向量是这一套。落库留给第 6 章。

5.1 向量是一串数

比较规章之前，先有一个能放进计算的对象。向量就是有顺序的一串数，本课这一串的长度是 4。

问题：问句和一条规章，要收成什么样的对象才能互相比较？

约定：向量记作 \(\mathbf v=(v_1,v_2,v_3,v_4)\)。下标从 1 数到 4，顺序就是坐标的一部分。维数记作 embedDim，本课为 4。这些数是教学用的坐标，不写「元」，也不是字数。两条向量能逐分量相乘，前提是长度相同。

基准算例：Course.data.agent.embedDim 是 4。问句向量 query 是 \([3,1,0,0]\)，第 1 个分量是 3，第 2 个分量是 1，后两个是 0。四条 clauses 依次是 \([0,1,0,0]\)、\([1,0,1,0]\)、\([3,1,0,0]\)、\([0,0,1,1]\)，名称依次是考勤、请假、报销、差旅。教学句「上周报销超了：上限 200 元，这单填了 350 元。」仍是前面章节的那句话，它不在这五个向量里再占一条。

const agent = Course.data.agent; const dim = agent.embedDim; const query = agent.query; const clauses = agent.clauses; // dim 为 4。query 为 [3, 1, 0, 0]。 // 四条依次是 clauses[0] 到 clauses[3]。

示例代码：examples/ch05/vector-row.js

易错：把维数改成 768

有的模型说明书写 768 或其他维数。那是另一套模型的长度。embedDim 改成 768 之后，问句仍是 4 个数，四条仍是 4 个数，长度对不齐，后面的点积没有定义。本课只读 Course.data.agent.embedDim，值是 4。

避坑：打乱四个分量的顺序

\([3,1,0,0]\) 的第 1 个分量是 3。把 3 换到第 2 个位置，得到的就不再是 query。和四条比较时，第 1 维只和第 1 维相乘。分量顺序保持 agent.query 与 agent.clauses 里的写法。

可操作对象：打开档案时先读 embedDim、query、clauses、clauseNames。四条数组的长度都是 4，和第 1 到第 4 条一一对应。clauses[2] 是第 3 条「报销」。

5.2 词向量对不上整句问题

长度已经定成 4。这一串数还要看它代表一个字，还是代表整句。词向量对不上这句问话。

问题：问句里有一个「报」字，能不能拿这个字去对四条规章？

约定：词向量是一个词或一个字自己的向量。句向量是整句收成的一个向量。词向量模型和句向量模型不是同一件工具。本课检索用句向量这一套，维数是 embedDim 的 4。符号上，字的向量不进入 \(\mathbf q\)。

基准算例：问句文本是「报销上限是多少」。其中的「报」是一个字。四条名称里，只有「报销」含这个字；考勤、请假、差旅都不含。名称里有没有「报」，看的是字形。它不是 query 的 \([3,1,0,0]\)，也算不出 5.4 节的余弦。

易错：用字符「报」去对四条

看见「报销」里有「报」，就把第 3 条记成命中。这时对上的是名称里的一个字，四条向量一个都还没有参加比较。第 3 条要成为命中，得等整句向量做完余弦，读数是 1 的那一条。

避坑：把两种模型当成同一件工具

词向量模型给字或词各一个向量，句向量模型给整句一个向量。换用词向量之后，坐标含义和 clauses 里的 4 个数对不上。本课四条规章的检索只走句向量，调用的是 Course.agentMath.scores()。

可操作对象：检索入口只接受整句。单字「报」不写入 query，也不拿去和 clauseNames 做包含判断。包含判断的结果不叫余弦。

5.3 句向量把整句收成一个 4 维向量

词向量已经放下。问句整句收成一个 4 维向量，每一条规章也同样收成一个。

问题：「报销上限是多少」这一整句，在档案里是几个向量？

约定：一句对应一个向量，长度是 4。问句记作 \(\mathbf q\)，第 \(i\) 条规章记作 \(\mathbf c_i\)，\(i\) 从 1 到 4。文本和向量分开放：文本给人读，向量给余弦用。本课不把一句拆成几个字再各配一个向量。

基准算例：agent.ask 是「报销上限是多少」，它的句向量就是 agent.query，即 \([3,1,0,0]\)。四条句向量就是 agent.clauses。第 3 条名称是「报销」，向量与问句相同，都是 \([3,1,0,0]\)。相同的是这两个 4 维向量，两段文本一个是问句、一个是规章名称。

const agent = Course.data.agent; const ask = agent.ask; const query = agent.query; // ask 是整句「报销上限是多少」，对应向量 query。 // 单字「报」没有单独的向量。检索用的是句向量这一套。

示例代码：examples/ch05/whole-sentence.js

易错：教学句或单字占用了 query

「上周报销超了：上限 200 元，这单填了 350 元。」是前面章节的教学句，本课没有另给它一个向量。单字「报」也没有。能拿去和四条做余弦的，只有 ask 对应的 query。

避坑：一条规章拆成多个字向量

四条在 clauses 里各是一个长度为 4 的数组。把「报销」拆成「报」和「销」两个向量之后，就不再是第 3 条那一个 \(\mathbf c_3\)。比较时一条规章只取出 clauses[i] 这一个数组。

可操作对象：下面的分段只改变「拿什么去对四条」。整句这一档使用 query 和 scores()；单字这一档不产生命中。

按单字，还是按整句切换分段，看哪一档出现命中
观察要点：① 切到「按整句」时，问句是「报销上限是多少」这一个向量，命中条号是 3，名称是报销。② 切到「按单字」时，拿出来的是字符「报」，命中条号是「无」。③ 「报销」里虽然有「报」，含这个字的卡片不会带上命中。④ 整句这一档的四个余弦来自 scores()：第 1 条考勤、第 2 条请假、第 3 条报销、第 4 条差旅。

5.4 余弦公式与单位（无量纲）

问句和四条都有了 4 维句向量。下一步用余弦看方向是否接近。这个读数没有单位。

问题：两个向量怎样比「方向近不近」，比完的数用什么单位？

约定：点积 \(\mathbf q\cdot\mathbf c=q_1c_1+q_2c_2+q_3c_3+q_4c_4\)。范数 \(\|\mathbf v\|=\sqrt{\mathbf v\cdot\mathbf v}\)。余弦

\[ \cos(\mathbf q,\mathbf c)=\frac{\mathbf q\cdot\mathbf c}{\|\mathbf q\|\,\|\mathbf c\|} \]

假设 \(\mathbf q\) 与 \(\mathbf c\) 都是实数，长度都是 4，两个范数都不为 0。分子分母同为坐标算出来的量，相除之后没有单位，不写「元」，也不写「维」。实数向量的余弦落在 \([-1,1]\)。本课这五个向量的分量都大于或等于 0，四个读数都落在 \([0,1]\)。越接近 1，方向越接近问句。

基准算例：\(\|\mathbf q\|=\sqrt{3^2+1^2}=\sqrt{10}\)。四条范数依次是 \(1\)、\(\sqrt{2}\)、\(\sqrt{10}\)、\(\sqrt{2}\)。本课不手写另一套小数：页面上的余弦只读 Course.agentMath.scores() 返回的 score。和分数对照时，第 3 条为 1，第 1 条为 \(1/\sqrt{10}\)，第 2 条为 \(3/\sqrt{20}\)，第 4 条为 0。

易错：给余弦加上单位

把 1 读成「1 元」或「1 维」，就和上限 200 元、超出 150 元这些带单位的数混在一张表里。余弦是两个长度相除，读数 1 表示方向相同，单位栏空着。

避坑：用欧氏距离替换本课余弦

欧氏距离 \(\|\mathbf q-\mathbf c\|\) 和向量分量同一类量，不是本课的读数。第 3 条与问句的差是零向量，距离是 0；第 4 条的差是 \([3,1,-1,-1]\)，距离是 \(\sqrt{12}\)，余弦却是 0。距离里的 0 表示两个向量相同，余弦里的 0 表示不相关。本课排序只看 scores()，余弦越大越近。

避坑：向量各自归一化两次

公式里已经用 \(\|\mathbf q\|\) 和 \(\|\mathbf c\|\) 各除了一次。余弦对每个向量再乘一个正数并不改变结果，所以把向量先收成单位向量再调用同一种余弦，四个读数仍是原来的四个。若在分母上再各除一次，第 3 条从 1 变成 \(1/10\)，第 1 条从 \(1/\sqrt{10}\) 变成 \(1/10\)，第 2 条从 \(3/\sqrt{20}\) 变成 \(3/20\)，第 4 条仍是 0。这套新数不是 scores() 的 score。不要改 query 和 clauses，每个余弦只取一次 scores()。

可操作对象：计算文件里的 cosine 是点积除以两个范数的乘积，范数为 0 时返回 0。本章读四条时调用 scores()，不在页面里再写一个除法。

5.5 用四条走一遍

公式已经定了。把四条向量逐条代进去，得到四个读数，并记下每个读数是谁。

问题：考勤、请假、报销、差旅，相对问句的余弦各是多少？

约定：第 \(i\) 条的读数是 \(\cos(\mathbf q,\mathbf c_i)\)。点积和范数都用 5.4 节的定义。四个分数是正文里的精确值；若要看小数，只格式化 scores() 的 score，不另算一套再抄进来。

基准算例：\(\mathbf q=[3,1,0,0]\)。

  • 第 1 条考勤 \([0,1,0,0]\)：点积 \(1\)，范数 \(1\)，余弦 \(1/\sqrt{10}\)。
  • 第 2 条请假 \([1,0,1,0]\)：点积 \(3\)，范数 \(\sqrt{2}\)，余弦 \(3/(\sqrt{10}\sqrt{2})=3/\sqrt{20}\)。
  • 第 3 条报销 \([3,1,0,0]\)：点积 \(10\)，范数 \(\sqrt{10}\)，余弦 \(10/10=1\)。
  • 第 4 条差旅 \([0,0,1,1]\)：点积 \(0\)，范数 \(\sqrt{2}\)，余弦 \(0\)。范数不是 0，读数是 0 是因为点积是 0。

易错：手写另一套小数

把 \(1/\sqrt{10}\) 和 \(3/\sqrt{20}\) 各自截成一个小数抄进页面，就和 scores() 的 score 分成了两套。正文保留上面的四个分数。演示里柱子上的小数只来自这次调用的返回值。

避坑：只比点积、不除范数

点积是 1、3、10、0。第 3 条的 10 最大，方向和第 3 条仍一致，但 10 不是余弦。余弦还要除以 \(\sqrt{10}\) 和该条的范数。第 2 条的分子是 3，除完才是 \(3/\sqrt{20}\)，这个数小于 1。

可操作对象：scores() 返回四项，每项有 clause、name、score。顺序与四条相同。下面的图用这四项画柱，点一条就读那一项的 score。

观察要点：① 左起第 1 根是第 1 条「考勤」，高度是 scores() 的第 1 个 score，正文公式是 \(1/\sqrt{10}\)。② 第 2 根是第 2 条「请假」，公式是 \(3/\sqrt{20}\)，低于第 3 根。③ 第 3 根是第 3 条「报销」，高度为 1，四根里最高。④ 第 4 根是第 4 条「差旅」，高度为 0；这个 0 是不相关，查询仍然算出了四个读数。

5.6 最近的是第 3 条

四个读数都在。其中最大的是第 3 条，余弦为 1。

问题：哪一条离问句最近，这个「最近」读的是哪个数？

约定：本课「更近」指余弦更大。最大的余弦是 1，它是实数余弦的上界，所以没有任何一条的余弦比 1 更大。比较 \(3/\sqrt{20}\) 与 1 时，先看 \(\sqrt{20}\) 是否大于 3：\(20>9\)，所以 \(\sqrt{20}>3\)，从而 \(3/\sqrt{20}<1\)。

基准算例：四条余弦里，第 3 条「报销」是 1，第 2 条「请假」是 \(3/\sqrt{20}\)，第 1 条「考勤」是 \(1/\sqrt{10}\)，第 4 条「差旅」是 0。从大到小是第 3 条、第 2 条、第 1 条、第 4 条。read-scores.js 里用 score 更大者替换 nearest，停在第 3 条。5.3 节的分段里，只有「按整句」把这一条标成命中。

易错：把余弦 1 说成完全相等的原文

问句文本是「报销上限是多少」，第 3 条名称是「报销」，两串字不同。余弦为 1，是因为两个向量都是 \([3,1,0,0]\)，方向相同，本题里分量也相同。它不表示规章原文和问句逐字相同。

避坑：把第 2 条说成比第 3 条更近

第 2 条的分子是 3，看起来不小。除以 \(\sqrt{20}\) 之后它小于 1。第 3 条的余弦是 1，仍然是更近的那一条。只拿分子 3 去和第 3 条的余弦 1 比，会把次序说反。

可操作对象：在四条余弦图里点「第3条」，读数区的余弦来自 scores() 的第 3 项，正文里这个值是 1。再点「第2条」，读数低于第 3 条。命中只保留余弦最大的这一条。

5.7 第 4 条余弦为 0，不能当命中

最近的一条已经认出。第 4 条的 0 还要单独读：它是不相关，查询没有失败。

问题：第 4 条余弦是 0 的时候，这次查询算不算失败？

约定：余弦 0 表示两个向量的点积是 0，本课把这种关系叫作不相关。查询失败指四个读数没有算出来。0 是算出来的一个读数，可以和其他三条放在同一张表里，只是不能标成命中。

基准算例：第 4 条「差旅」是 \([0,0,1,1]\)。与问句的点积 \(3\cdot 0+1\cdot 0+0\cdot 1+0\cdot 1=0\)。范数 \(\sqrt{2}\) 不为 0，所以余弦就是 0，不是「除以 0」。四条的 scores() 都会返回。clause 为 4 的那一项 score 是 0，名称是差旅。命中仍是第 3 条。

易错：余弦为 0 就把第 4 条从档案里删掉

删掉之后表里只剩三条，clauseCount 仍是 4，条号会错位。第 4 条留在 clauses 里，柱子画在第 4 个位置，高度为 0，命中标记不放在它上面。

避坑：把 0 当成查询失败

失败会让四条都没有读数。这里第 1 条到第 3 条都有余弦，第 4 条的 0 表示差旅和问句不相关。重试同一套向量，这个 0 还在。不能当命中的是第 4 条，整次查询已经完成。

可操作对象：在余弦图里点「第4条」。读数是 scores() 的最后一项。命中条号仍看最大的 score，那是第 3 条，不是第 4 条。

5.8 索引和查询必须同一套向量，落库留给第 6 章

四条里谁近、谁不相关，已经能从余弦读出来。这些读数成立的前提，是索引和查询用同一套向量。把它们写入库留给第 6 章。

问题：四条向量和问句向量，能不能各用一套坐标？

约定：同一套向量指三件事一起成立：都是句向量，维数都是 4，第 \(k\) 个分量的含义相同。索引里的 \(\mathbf c_i\) 和查询时的 \(\mathbf q\) 来自这一套。换一套之后，scores() 的四个数不再表示这次比较。模型说明里的参数以该模型文档原文为准；本课档案不改用那些维数。

基准算例：索引侧是 clauses 的四条，查询侧是 query。两边都是 4 维，余弦就是 5.5 节那四个数，最近的仍是第 3 条。若查询改用词向量，或改成 768 维，就没有和 \([0,1,0,0]\) 这一条逐分量相乘的定义。本章停在这一套坐标上。切片、写入索引、再按同一套向量取回，是第 6 章的内容。

易错：索引用一套，查询用另一套

四条已经按本课句向量放好，查询却改用词向量或另一套维数。点积的每一项不再是「同一含义的分量相乘」，第 3 条的余弦 1 也不能沿用。索引和查询都读 Course.data.agent 里的 query 与 clauses。

避坑：在这一章换一套坐标并写入库

落库要保存的是现在这一套 4 维句向量，写入和取回的步骤在第 6 章。本章先把四个余弦核对完：第 3 条为 1，第 1 条为 \(1/\sqrt{10}\)，第 2 条为 \(3/\sqrt{20}\)，第 4 条为 0。

可操作对象：核对时列出两边的来源。索引：agent.clauses 四条。查询：agent.query 一条。计算：Course.agentMath.scores()。三处都指向这一套，才把第 3 条留下作为最近的规章。

本章避坑清单

  1. 用欧氏距离替换本课余弦。第 4 条余弦是 0，欧氏距离是 \(\sqrt{12}\)。距离里的 0 和余弦里的 0 不是同一个量。
  2. 把第 2 条说成比第 3 条更近。\(3/\sqrt{20}<1\)。更近看余弦更大的那一条，是第 3 条。
